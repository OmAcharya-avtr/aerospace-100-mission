# Dataset card — `calibaudit` synthetic forecast samples

Every dataset in this repository is **synthetic and generated by committed
code from a fixed seed.** No data file is committed: the largest file in the
repository is a PNG. There is no measured aerospace forecast here, and that
absence is a limitation of every number in the repository.

## Why synthetic, and what it buys

The product measures the *bias of a calibration estimator*. A bias is a
difference from a true value, so a true value is required, and no real dataset
has one. The construction here provides one in closed form.

## Generative model

`calibaudit.synthetic.sample_forecast`. Stated in full in that module's
docstring and reproduced here, because a dataset card that hides its generator
is useless.

1. `rng = numpy.random.default_rng(seed)`.
2. Latent success probability, drawn in **one** call:
   `p = rng.beta(a, b, size=n)`.
3. Outcome, drawn in **one** call from the same stream:
   `o = (rng.random(n) < p).astype(float)`, so `o | p ~ Bernoulli(p)`.
4. Forecast: `f = g(p)` for a declared strictly increasing distortion `g`.

Drawing either array in more than one call, or reordering steps 2 and 3,
changes the stream and so changes every number. **Sample size is part of the
seed:** a draw of 200 is not a prefix of a draw of 400 in the outcomes, which
`tests/test_synthetic.py` asserts in both directions.

## What is known exactly, and how

Because `f` is a deterministic monotone function of `p`, conditioning on `f`
is conditioning on `p`, so the calibration curve is exactly
`E[o | f] = g^{-1}(f)`. The population quantities follow:

| Quantity | How it is obtained | Exactness |
|---|---|---|
| base rate `obar = a/(a+b)` | closed-form Beta mean | exact |
| uncertainty `UNC = obar(1-obar)` | closed form | exact |
| resolution `RES = Var(p) = ab/((a+b)²(a+b+1))` | closed-form Beta variance | exact |
| reliability `REL = E[(g(p)-p)²]` | `scipy.integrate.quad` | `abserr` carried on `AnalyticTruth.reliability_abserr` |
| Brier `BS = REL - RES + UNC` | the three above | exact given the above |
| `ECE = E[|g(p)-p|]` | `scipy.integrate.quad` | `abserr` carried on `AnalyticTruth.ece_abserr` |
| log score `LS = E[-(p log g(p) + (1-p) log(1-g(p)))]` | `scipy.integrate.quad` | `abserr` carried on `AnalyticTruth.log_score_abserr` |

Quadrature settings: `limit=400`, `epsabs=1e-12`. The three calibrated specs
need no quadrature for `REL` or `ECE` — both are exactly 0 and are returned as
such, with `abserr` 0. For the other values the measured `abserr` runs from
**5.55e-16** (`calibrated_uniform` log score) to **5.74e-09**
(`underconfident` log score), and the quad bound is conservative: for the
Beta(2,2) calibrated spec the reported `abserr` is **5.66e-09** while the
actual error against the hand integral `7/12` is **2.863e-13**
(`tests/test_known_answers.py`; both derivations and both comparisons are
printed by `validation/validate_decomposition_identity.py` section 6 and
committed in `validation/outputs/validate_decomposition_identity_output.txt`).
Full per-spec values, from that same output:

| Spec | `reliability_abserr` | `ece_abserr` | `log_score_abserr` |
|---|---|---|---|
| `calibrated` | 0.00e+00 | 0.00e+00 | 5.66e-09 |
| `calibrated_uniform` | 0.00e+00 | 0.00e+00 | 5.55e-16 |
| `calibrated_rare` | 0.00e+00 | 0.00e+00 | 6.10e-11 |
| `overconfident` | 6.13e-11 | 1.79e-10 | 2.13e-09 |
| `underconfident` | 3.18e-11 | 3.04e-10 | 5.74e-09 |
| `biased_high` | 1.66e-16 | 1.31e-15 | 5.51e-09 |

Two of the log-score values reduce to hand integrals and are asserted as
known answers:

- Beta(2,2), identity: `LS = -12 ∫ (p² - p³) ln p dp = -12 (-7/144) = 7/12`
  = 0.5833333333333333. Measured by quadrature: **0.583333333333047**.
- Beta(1,1), identity: `LS = -2 ∫ p ln p dp = 1/2`. Measured:
  **0.49999999999999983**.

## The six shipped specs

| Spec | `a` | `b` | Distortion `g(p)` | Base rate | Population ECE | Population BS |
|---|---|---|---|---|---|---|
| `calibrated` | 2 | 2 | `p` | 0.5 | **0 exactly** | 0.200000 |
| `calibrated_uniform` | 1 | 1 | `p` | 0.5 | **0 exactly** | 0.166667 |
| `calibrated_rare` | 1 | 9 | `p` | 0.1 | **0 exactly** | 0.081818 |
| `overconfident` | 2 | 2 | `sigmoid(logit(p)/0.6)` | 0.5 | 0.075204 | 0.206778 |
| `underconfident` | 2 | 2 | `sigmoid(logit(p)/1.6)` | 0.5 | 0.059354 | 0.204562 |
| `biased_high` | 2 | 2 | `sigmoid(logit(p)+0.6)` | 0.5 | 0.117979 | 0.214976 |

Both shape parameters are at or above 1 in every shipped spec, which keeps the
Beta density bounded and the quadrature error near machine precision. Values
below 1 are accepted by `ForecastSpec` and put an integrable singularity at an
endpoint; the quadrature still converges but the `abserr` grows, and no
shipped spec relies on it.

`overconfident` is the shape a neural network classifier typically has after
training: confident beyond what its accuracy supports. `underconfident` is
what over-regularisation or a too-large temperature gives.
`calibrated_rare` is the hard case for any binned metric, because equal-width
bins leave most of [0, 1] empty.

## Limitations of the data

1. **It is not real.** Nothing here is a measurement of any forecasting system,
   aerospace or otherwise. Agreement between a measurement and a population
   value is evidence about the implementation, not about the world.
2. **The calibration map is monotone and smooth in every spec.** Real
   miscalibration can be non-monotone, which `PlattScaling` cannot represent
   and which no spec here exercises. That gap is stated, not measured.
3. **Outcomes are conditionally independent given `p`.** Real forecast-outcome
   records are serially correlated, which inflates every effective sample size
   and therefore every interval computed on them. Nothing here measures that,
   and a user applying this package to a correlated record will get intervals
   that are too narrow.
4. **The latent family is Beta and the distortion family is logistic.** Both
   are convenient rather than motivated by any aerospace forecasting problem.
5. **Only three base rates are shipped** (0.5, 0.5, 0.1). A base rate of 1e-3,
   which is where aerospace rare-event forecasting actually lives, is not
   represented, and the binned metrics behave much worse there than any number
   in this repository shows.

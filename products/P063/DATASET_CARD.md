# Dataset card — safemodetree synthetic observations 0.1.0

## 1. What this dataset is

A labelled set of observation vectors over the declared channels of a
`safemodetree` declaration, generated by
`safemodetree.data.make_observations`. It exists to benchmark the learned
fault classifier against the declared threshold-logic baseline. It is **not a
measurement of any vehicle** and contains no real telemetry.

No data file is committed. The dataset is a deterministic function of the
declaration, the generator arguments and the seed, and is regenerated on every
run.

## 2. Source

The declaration itself. For the shipped `reaction_wheel_fmea` declaration:

- 7 observation channels, each with a declared `nominal`, `threshold`,
  `faulted` value, `direction` and 1-sigma `noise_sd`, in units of A, s, deg,
  V, A, dimensionless and mN*m.
- 8 declared faults, each with a binary signature over those channels.
- the no-fault class, which is the all-zero signature.

## 3. Generating process

For a class with declared signature `s`, channel `j` is drawn independently
from

```
N( faulted_j , (noise_scale * noise_sd_j)^2 )   when s_j = 1
N( nominal_j , (noise_scale * noise_sd_j)^2 )   when s_j = 0
```

`noise_scale` is a declared, dimensionless difficulty multiplier applied to
every channel. Rows are then shuffled with the same generator.

Default size: `n_per_fault = 400` and `nominal_fraction = 0.5`, giving 3200
faulted rows (400 per fault) and 3200 no-fault rows, 6400 in total.

Seeds: `numpy.random.default_rng(seed)`. The benchmark uses seed 63001 for the
generator and 63002 for the train / calibration / test permutation.

## 4. Declared channel values of the shipped declaration

| channel | unit | nominal | threshold | faulted | direction | noise_sd | nominal margin [sigma] | faulted margin [sigma] |
|---|---|---|---|---|---|---|---|---|
| `wheel_current` | A | 0.22 | 0.42 | 0.68 | above | 0.05 | 4.00 | 5.20 |
| `wheel_speed_age` | s | 0.25 | 2.00 | 6.00 | above | 0.45 | 3.89 | 8.89 |
| `attitude_residual` | deg | 0.08 | 0.50 | 1.40 | above | 0.10 | 4.20 | 9.00 |
| `bus_voltage` | V | 28.00 | 26.00 | 24.20 | below | 0.40 | 5.00 | 4.50 |
| `array_current` | A | 2.10 | 1.20 | 0.55 | below | 0.18 | 5.00 | 3.61 |
| `tracker_valid_fraction` | dimensionless | 0.98 | 0.80 | 0.35 | below | 0.05 | 3.60 | 9.00 |
| `wheel_torque_error` | mN*m | 0.40 | 3.00 | 6.50 | above | 0.60 | 4.33 | 5.83 |

The margin columns are `|nominal - threshold| / noise_sd` and
`|faulted - threshold| / noise_sd` at `noise_scale = 1`, computed from the
columns to their left. They are why the benchmark is run as a sweep: at
`noise_scale = 1` the smallest margin is 3.60 sigma and both detectors are
nearly perfect, so the comparison is uninformative. The reported sweep is
`noise_scale` in {1.0, 1.5, 2.0, 2.5, 3.0}, where the smallest margin falls to
1.20 sigma and the declared thresholds fire on 41 per cent of no-fault rows.

## 5. Declared signatures

| fault | wheel_current | wheel_speed_age | attitude_residual | bus_voltage | array_current | tracker_valid | wheel_torque_error |
|---|---|---|---|---|---|---|---|
| `rw_bearing_drag` | 1 | 0 | 1 | 0 | 0 | 0 | 1 |
| `rw_motor_open` | 0 | 0 | 1 | 0 | 0 | 0 | 1 |
| `rw_tach_stale` | 0 | 1 | 0 | 0 | 0 | 0 | 0 |
| `st_blinding` | 0 | 0 | 1 | 0 | 0 | 1 | 0 |
| `st_latchup` | 0 | 0 | 1 | 0 | 0 | 1 | 0 |
| `bat_cell_short` | 0 | 0 | 0 | 1 | 0 | 0 | 0 |
| `sa_string_open` | 0 | 0 | 0 | 1 | 1 | 0 | 0 |
| `pcdu_shunt_stuck` | 0 | 0 | 0 | 1 | 1 | 0 | 0 |

`st_blinding` and `st_latchup` share a signature, and so do `sa_string_open`
and `pcdu_shunt_stuck`. **Those two pairs therefore have identical observation
distributions in the generated data, exactly and by construction.** The
generator does not leak a difference the declaration denies, so no classifier
can separate them better than the class prior, and the accuracy ceiling on a
balanced split is `(800 + 400 + 200) / 1600 = 0.875`.

## 6. Splits

A single random permutation, **not stratified**, into 50 per cent train, 25 per
cent calibration and 25 per cent test: 3200 / 1600 / 1600 rows at the default
size. The calibration split is where the detectors' operating points are
chosen; the test split is touched once, after both are fixed.

Per-class counts in each part differ by sampling noise and are reported by
`ObservationSet.counts()`; they appear in the committed validation output.

## 7. Limitations

1. **Entirely synthetic.** There is no real telemetry here and no claim that
   these distributions resemble any spacecraft's symptom channels.
2. **Channels are independent.** Real symptom channels are correlated: a bus
   voltage droop and an array current drop move together, a wheel current rise
   and a torque error move together. Independence is the simplest assumption
   and it is wrong.
3. **Gaussian noise.** Real monitor channels have heavy tails, quantisation,
   dropouts and stale samples. None of that is modelled. A Gaussian tail
   understates the rate of extreme excursions, so the measured false-alarm
   rates are optimistic for any real system.
4. **One sample per decision.** A real onboard monitor latches a symptom
   through a persistence filter over several samples, which changes both the
   false-alarm rate and the detection latency. This generator gives each
   decision one independent draw.
5. **Static.** There is no time axis, no fault onset transient, no propagation
   of one fault's effect into another channel, and no mode-dependent noise.
   The declared `detection_latency_s` is used by the deterministic core to
   decide actionability and is not simulated here.
6. **Fault classes are balanced.** 400 rows each. Real failure-mode rates
   differ by orders of magnitude, and a realistic prior would change every
   posterior reported in the model card.
7. **The nominal class is half the data.** A real system is in the no-fault
   state almost all the time, so a realistic prior would make the false-alarm
   rate dominate the cost accounting far more than it does here.
8. **The declared values are illustrative.** The channel numbers, thresholds,
   noise levels, latencies and response costs of the shipped declaration were
   chosen to exercise every check in the package — including two ambiguity
   classes and two vacuous responses — and are not taken from any programme's
   FMECA.

## 9. Regenerating

```bash
PYTHONPATH=src python -c "
from safemodetree import load_spec, packaged_spec_path, make_observations
spec = load_spec(packaged_spec_path('reaction_wheel_fmea'))
obs = make_observations(spec, n_per_fault=400, noise_scale=2.0, seed=63001)
print(obs.features.shape, obs.counts())
"
```

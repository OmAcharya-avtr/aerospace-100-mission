# Fault taxonomy reference

Generated by `python -m faultinject taxonomy` from `src/faultinject/taxonomy.py`,
which is the single source of truth. Units, ranges and the coverage binning are
the ones the injection code actually enforces.

```
faultinject taxonomy: 16 kinds, 248 coverage cells

   sensor | sensor_bias
            channels: pos, vel   cells: 24
            param offset: [0.1, 10] channel units, 3 log bins
            Additive constant offset on the measurement while active.
            ref: Hwang et al. 2010, IEEE T-CST 18(3), Sec. II (additive sensor bias)

   sensor | sensor_drift
            channels: pos, vel   cells: 24
            param rate: [0.001, 0.5] channel units per step, 3 log bins
            Additive ramp on the measurement, accumulating from the start step.
            ref: Hwang et al. 2010, IEEE T-CST 18(3), Sec. II (sensor drift)

   sensor | sensor_stuck
            channels: pos, vel   cells: 8
            param (none)
            Measurement frozen at its value on the step before injection began.
            ref: Hwang et al. 2010, IEEE T-CST 18(3), Sec. II (hard sensor failure)

   sensor | sensor_dropout
            channels: pos, vel   cells: 24
            param dropout_prob: [0.05, 1] probability, 3 linear bins
            Measurement marked invalid with the given per-step probability.
            ref: Avizienis et al. 2004, IEEE TDSC 1(1), Sec. 3 (omission fault)

   sensor | sensor_quant_collapse
            channels: pos, vel   cells: 24
            param lsb: [0.05, 20] channel units, 3 log bins
            Measurement quantised to a coarse LSB (ADC resolution collapse).
            ref: IEEE 754-2019 Sec. 4 rounding; quantisation-noise model, Widrow 1961

            ref: Avizienis et al. 2004, IEEE TDSC 1(1), Sec. 3 (omission fault)

            param late_steps: [1, 4] step, 2 linear bins (integer)
            Sample arrives after the controller has read the port, so the stale value from N steps earlier is used.

   timing | timing_overrun
            channels: bus   cells: 12
            param overrun_prob: [0.1, 1] probability, 3 linear bins
            Controller task overruns its period; the previous command is held and the step's update is skipped.
            ref: Buttazzo 2011, Hard Real-Time Computing Systems, 3rd ed., Sec. 4 (deadline miss)

numerical | numerical_nan
```

9g. the operator's declaration is the only guard against a false claim
==============================================================================
preflight(expect_hardware=...) makes the operator state what they believe,
and a mismatch against the backend's own is_hardware flag is a failed check.
Every backend in this repository reports is_hardware=False, so a run written
up as a board measurement would have had to pass expect_hardware=True and
ignore a failing check to do it.

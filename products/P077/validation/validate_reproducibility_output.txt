==============================================================================
different seeds do produce different runs
==============================================================================
Reproducibility is only interesting if the seed does something. If two
different seeds gave the same run, every check above would pass trivially.

Unacknowledged mode sends every unit exactly once whatever the seed, so its
transmission count is deterministic by construction and the quantity that
has to vary there is how many units ARRIVED. The first run of this check used
the transmission count for all three modes and reported a false failure on
all three unacknowledged rows. The criterion column below names which
quantity each row is judged on.

               link            mode  distinct tx  distinct recv  distinct times   criterion  varies
---------------------------------------------------------------------------------------------------
   clean continuous  unacknowledged            1              1               1    received   False
   clean continuous    deferred_nak            1              1               1          tx   False
   clean continuous   immediate_nak            1              1               1          tx   False
   lossy continuous  unacknowledged            1             15               0    received    True
   lossy continuous    deferred_nak           18              1              41          tx    True
   lossy continuous   immediate_nak           18              1              51          tx    True
    windowed bursty  unacknowledged            1             25               1    received    True
    windowed bursty    deferred_nak           26              1              35          tx    True
    windowed bursty   immediate_nak           25              1              42          tx    True

The clean continuous link is deterministic by construction -- no loss and no
outages -- so one distinct value there is the correct answer, not a defect,
and those three rows are excluded from the verdict.
seed sensitivity on the stochastic links: True

# Dataset card: synthetic combiner dataset

**Package:** `aperturediv` 0.1.0 · **Module:** `aperturediv.datasets` ·
Apache-2.0 · © 2026 OPTIMA Organisation

Research-grade. Not flight-qualified, not certified, not approved for
operational aerospace use.

## 1. What this is, and what it is not

A synthetic dataset of receiver states for a multi-aperture free-space
optical link under scintillation. **It contains no measured data.** It is
generated by `aperturediv.datasets.make_combiner_dataset` from a seed, and
nothing is committed to the repository: no `.npz`, no `.joblib`, no CSV.
Regeneration is deterministic, so every number in `MODEL_CARD.md` and in
`validation/` comes back exactly from the seeds recorded there.

It is a channel-model sample, not an observation of the atmosphere. A model
fitted to it has learned the properties of the model in
`aperturediv.channel`, `aperturediv.correlation` and
`aperturediv.estimation` — not of any real link.

## 2. One row

One row is one symbol interval at one receive array of `L` apertures:

| field | shape | meaning |
|---|---|---|
| `irradiance_true` | `(L,)` | normalised irradiance per aperture, `E[I] = 1` |
| `irradiance_estimated` | `(L,)` | what the receiver has, mean-unbiased given the truth |
| `sigma_e` | scalar | log-domain estimation error standard deviation for this row |
| `features` | `(L + 3,)` | `ln Ihat_k`, then mean and std of those logs, then `sigma_e` |
| `weights_optimal` | `(L,)` | `h/||h||` with `h = sqrt(I)`: the MRC direction, the label |

`features` is built by `build_features(irradiance_estimated, sigma_e)`, which
takes no argument carrying the truth. The label is therefore not reachable
through the feature path, and that is asserted in the test suite rather than
asserted in prose.

## 3. Generative process

1. **Spatial geometry.** `L` apertures on a line at pitch
   `aperture_spacing_m`. The log-irradiance correlation matrix is
   `R_jk = exp(-(d_jk / rho_c)^2)` with `rho_c = correlation_scale_m`.
2. **True irradiance.** A Gaussian copula in the log domain: `Z ~ N(0, R)` by
   Cholesky, then `I = exp(s Z - s^2/2)` with `s^2 = ln(1 + si)`. Every
   marginal is exactly the unit-mean lognormal of `aperturediv.channel`, and
   the log-domain correlation is exactly `R`.
3. **Error level.** `sigma_e` drawn uniformly per row from `sigma_e_range`.
   Drawn per row, not per dataset, so one model covers the whole error range
   and `sigma_e` is a feature rather than a hyperparameter.
4. **Estimate.** `ln Ihat = ln I + sigma_e u - sigma_e^2 / 2` with
   `u ~ N(0,1)` independent across apertures, so `E[Ihat | I] = I` and any
   loss is attributable to variance rather than bias.
5. **Label.** `h = sqrt(I)`, `w* = h / ||h||`.

Every draw comes from one `numpy.random.default_rng(seed)` stream in that
order, so the dataset is a pure function of `(n_samples, n_apertures, si,
aperture_spacing_m, correlation_scale_m, sigma_e_range, seed)`.

## 4. Headline configuration

Used by `validation/validate_learned_combiner.py` and `MODEL_CARD.md`:

| parameter | value |
|---|---|
| `n_samples` | 120000 |
| `n_apertures` | 4 |
| `si` | 0.9 |
| `aperture_spacing_m` | 0.15 |
| `correlation_scale_m` | 0.10 |
| adjacent log correlation | 0.105399 |
| `sigma_e_range` | (0.0, 3.0), i.e. 0 to 13.03 dB of irradiance |
| `seed` | 44044 |
| memory in RAM | about 16 MB of float64 |
| generation time | 0.4 s on one core |

The example `examples/learned_combiner_vs_baselines.py` uses the same 120000
rows and the same split; `python -m aperturediv combiner` defaults to 60000.
The aperture-count sweep in `validate_learned_combiner.py` check 7 regenerates
at 45000 rows per `L`. All three sizes are set by the compute budget — 2
cores shared with four sibling agents — and not by accuracy; an earlier
250000-row configuration gave the same conclusions and took 440 s of wall
clock instead of 184 s.

## 5. Splits

`split_dataset(dataset, n_train, n_validation)` splits by row index into
train, validation and test, in that order, with no overlap. The headline
split is 70000 / 25000 / 25000.

An index split is valid here because rows are i.i.d. draws of independent
symbol intervals: there is no temporal, spatial or subject structure that
could leak across the boundary. The per-error-level evaluation sets in the
validation script are generated from *separate* seeds, so they share no row
with the training split at all.

Every baseline and the learned model are scored on the same test rows.

## 6. Composition

At the headline configuration, over the 120000 rows:

- `sigma_e` is uniform on [0, 3.0] by construction, so every error level is
  equally represented. Any pooled figure is therefore an average over a
  *uniform* error distribution, which is a modelling choice and not a
  prediction of how often a real receiver is in each regime. The per-level
  tables in `MODEL_CARD.md` exist because the pooled figure alone would be
  misleading.
- Marginal irradiance: unit mean, scintillation index 0.9, lognormal.
- Inter-aperture log correlation: 0.1054 (adjacent), 0.0001 (outermost pair)
  — a deliberately *weakly* correlated array, so that the learned-combiner
  study is not confounded with the correlation study. The correlation study
  uses a tighter array (pitch 0.05 m, `rho_c` 0.10 m, adjacent log
  correlation 0.7788).

## 7. Known limitations

- **Synthetic.** No measured irradiance time series was used, and no
  comparison against one has been made. This is the dataset's principal
  limitation and it cannot be fixed inside this repository.
- **Lognormal only.** The combiner dataset uses the lognormal marginal. At
  `si = 0.9` that is at the edge of the weak-fluctuation regime where the
  lognormal model is justified; a gamma-gamma marginal would give a heavier
  deep-fade tail (measured: more than 3x the outage at 1e-3 at matched
  scintillation index, `tests/test_integration.py`). The learned combiner has
  not been retrained or evaluated on gamma-gamma branches.
- **Memoryless in time.** Each row is an independent symbol interval. A real
  receiver sees fades lasting milliseconds, so successive symbols are
  correlated; staleness is modelled through its effect on `sigma_e` only, not
  as a time series. Nothing here supports a claim about interleaver depth or
  feedback latency.
- **Independent estimation noise across apertures.** Real estimator noise may
  be common-mode (a shared gain or bias). Only the independent case is
  generated.
- **Identical marginals across apertures.** Every aperture has the same
  `si`; a real array with unequal apertures or vignetting does not.
- **One geometry per dataset.** `si`, pitch and `rho_c` are fixed per
  dataset, so a model fitted to one cannot be assumed to transfer. The `L`
  sweep in the validation script refits from scratch for each `L`.
- **`sigma_e` is assumed known to the receiver.** It is a feature. A receiver
  that mis-estimates its own estimator accuracy is not modelled.

## 8. Regeneration

```bash
pip install -e ".[dev]"
python - <<'PY'
from aperturediv.datasets import make_combiner_dataset, split_dataset
data = make_combiner_dataset(
    120_000, n_apertures=4, si=0.9, aperture_spacing_m=0.15,
    correlation_scale_m=0.10, sigma_e_range=(0.0, 3.0), seed=44044,
)
train, val, test = split_dataset(data, n_train=70_000, n_validation=25_000)
print(len(train), len(val), len(test), data.features.shape)
PY
```

Or simply run `python validation/validate_learned_combiner.py`, which
regenerates the dataset, the splits, the fits and every reported number.

  For L >= 2, P(SC > EGC) is not zero, so the textbook ordering EGC >= SC
  is false pointwise; it holds only in the mean. Selection wins on exactly
  the realisations where one branch is in a deep fade. At L = 1 all three
  schemes are the same quantity and the probability is identically zero.

8. The lognormal case has no finite asymptotic diversity order
==============================================================================
  Measured slope for independent lognormal branches in three successive
  windows. A finite diversity order would give the same slope in all three.
   L   window 1e-02-1e-01   window 1e-03-1e-02   window 1e-05-1e-03
   1                 2.738                 3.721                 4.693
   2                 3.783                 5.253                 6.805
   3                 4.577                 6.299                 8.666
   4                 5.220                 7.204                 9.154
  slope increases monotonically as the window moves down, every L: True
  So 'diversity order L' is not a property of a lognormal channel. For
  gamma-gamma it is, because the gamma-gamma density has a power-law tail
  at small irradiance and the lognormal does not.

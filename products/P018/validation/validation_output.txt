3. Slope error vs photon count vs the standard noise-propagation expression
==============================================================================
Expression (Hardy 1998 ch. 5; Thomas et al. 2006, MNRAS 371, 323; photon-limited
form also in Winick 1986, JOSA A 3, 1809), derived in slopes.cog_noise_sigma:
    Var(x) = M2/N + (B + R^2)/N^2 * [p^2(p^2-1)/12 + p^2 d^2]   [px^2]
    sigma_g = sqrt(Var(x)) * p_pix / f                          [rad]
M2 is evaluated numerically from the pixel-integrated spot profile.
It describes the LINEAR (un-thresholded, un-clipped) CoG on background-
subtracted data, which is the estimator measured in the first table.

B = 1.0 e-/px, R = 3.0 e- RMS, 4000 stamps per point, slopes uniform over +/- 0.6 of the field.

4. Centre-of-gravity bias under an unsubtracted background offset
==============================================================================
Analytic prediction. With a uniform background B added to every pixel and no
threshold, the CoG numerator gains B*sum(x_i) = 0 (the pixel grid is centred)
and the denominator gains B*p^2, so
    x_hat = S*d / (S + B*p^2) = d * kappa,   kappa = S / (S + B p^2)
i.e. a pure multiplicative shrinkage of every measured slope toward zero — a
gain error on the whole wavefront, not a random error. Noise-free frames.

p^2 = 256 pixels per subaperture

Worst deviation from the analytic shrinkage: 1.39e-05 px (tolerance 1e-3 px) -> PASS
Magnitude of the effect, quoted as measured-slope / true-slope:
  S =  1000 e-, B =  0.5 e-/px ->  88.7 % of truth, i.e. a 11.3 % wavefront gain error
  S =  1000 e-, B =  2.0 e-/px ->  66.1 % of truth, i.e. a 33.9 % wavefront gain error
  S =  1000 e-, B = 10.0 e-/px ->  28.1 % of truth, i.e. a 71.9 % wavefront gain error
  S =  5000 e-, B =  2.0 e-/px ->  90.7 % of truth, i.e. a  9.3 % wavefront gain error
  S =  5000 e-, B = 10.0 e-/px ->  66.1 % of truth, i.e. a 33.9 % wavefront gain error
Subtracting B, or thresholding at B, removes it (see the threshold column in
section 3). This is why an uncorrected background offset is a systematic
wavefront error and not merely extra noise.

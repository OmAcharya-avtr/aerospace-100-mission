(3) peak memory
------------------------------------------------------------------------------

--- target: analytic peak memory [B] ---
  range: 3408 to 3566984 B (1047x)
  The analytic peak memory is EXACT by construction: it is integer byte
  arithmetic over the graph's tensor shapes plus a liveness analysis, and
  validate_memory.py checks it against a measured execution. Its error
  against itself is zero, so there is no accuracy for a learned model to
  add. What follows is the cost of using one anyway.
      predictor               : learned forest, memory features ablated
      n (held out)            : 36
      median |rel error|      : 11.17 %
      p90 |rel error|         : 62.65 %
      max |rel error|         : 100.55 %
      Spearman rho            : 0.9920
      RMSE in log10 space     : 0.1358
      analytic error on the same models: 0.00 % (exact arithmetic)
      so the learned model is worse by 11.17 pp at the median and
      62.65 pp at p90, and it needs the population to have been
      measured first. For peak memory the analytic model wins outright.

5. A CONSTRUCTED VALID-BUT-STALE ELEMENT SET, THE DECLARED CONTROL
==============================================================================
The control is a genuine, uncorrupted element set whose only defect is its age. It is constructed with tlecheck.dataset.rewound, which runs the propagator back to the older epoch and writes the mean elements it computed there, so the element set describes the same orbit at an earlier time. Nothing in its characters is wrong: the checksum is valid, every element is inside every bound, and the propagator reports success.

Stamping an earlier epoch onto an element set without moving its angles does NOT produce an older element set, it produces a different orbit. The first version of this control did that and measured 9752.6918 km at an age of 1.5 days, which is a meaningless number. The figures below are from the propagator-based construction.

A disagreement worth reporting rather than resolving. The declared epoch requirement of 7 days flags this element set from an age of 7.5 days onward, and the measured consequence first exceeds the declared 1 km threshold at an age of 30 days. For this object the staleness policy is the more conservative of the two by a factor of about four. Neither number is wrong: the requirement is an operational choice and the threshold is a different operational choice, and a screen that reported only one of them would be hiding the gap. The determinability report returns the requirement with every verdict for exactly this reason.

The rules both over-predict and under-predict a loud failure, and both are measured above. They over-predict because an element set whose eccentricity is implausible for its object sometimes still propagates, and when it does the measured class is silently wrong. They under-predict because an element set with a field this package cannot read is classified silently wrong rather than loud, deliberately: the propagator usually reads such a line without complaint, and predicting a loud failure from a parse failure drove the field-shift operating characteristic below chance.

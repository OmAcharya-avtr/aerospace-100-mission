2. the measured slip threshold, which is the usable number
----------------------------------------------------------
   loop SNR in dB at which the measured rate crosses 1e-04 slips per symbol,
   by log-linear interpolation between the two bracketing points
        B_n    threshold loop SNR dB   threshold rms (symbol)
      0.005                      nan                      nan
      0.010                   18.026                  0.06276
      0.020                   16.774                  0.07249
      0.050                   16.081                  0.07851
   measured here at 16.1 to 18.0 dB of loop SNR, i.e. a predicted rms timing error
   of 0.063 to 0.079 symbol. Expressed as an rms fraction of a symbol the threshold
   moves by only a quarter while B_n changes by a factor of five, so the design rule
   this package supports is a jitter rule, not a bandwidth rule: keep the predicted
   rms timing error below about 0.05 symbol and slips are unobservable in 200000
   symbols; let it reach 0.10 symbol and the loop is gone. At B_n = 0.005 the
   threshold is not located at all - the lowest SNR swept still gives only one slip
   in 200000 symbols - and that is reported as not located rather than extrapolated.

3. the Gaussian level-crossing estimate: how badly it fails
-----------------------------------------------------------
   over every point above with at least one observed slip, the ratio of the measured
   rate to the Rice estimate:
   B_n = 0.005  snr =   4.0 dB   measured / Rice = 9.237e+15
   B_n = 0.01   snr =   6.0 dB   measured / Rice = 1.858e+11
   B_n = 0.02   snr =   9.0 dB   measured / Rice = 3.719e+09
   B_n = 0.02   snr =   8.0 dB   measured / Rice = 3.816e+07
   B_n = 0.05   snr =  12.0 dB   measured / Rice = 1.107e+06
   the estimate is low by 6.0 to 16.0 orders of magnitude on these points.
   this is not a tuning problem and no fitted prefactor is offered. The Gaussian
   assumption is wrong in exactly the tail that produces slips, so the estimate's
   functional form is wrong, not just its scale. It is shipped because it is the
   classical answer and a user will otherwise reach for it; it is shipped with this
   measurement attached.

4. the mechanism: gain falls and noise rises together as the error grows
------------------------------------------------------------------------
   measured at fixed timing offsets, Mueller-Mueller at 8 dB per-sample SNR.
   'local gain' is the S-curve's own slope at that offset, by central difference.
     offset   S(offset)  local gain   sigma_n^2  ratio to 0
       0.00    0.000000    1.570784    0.309617      1.0000
       0.10    0.156597    1.556261    0.325158      1.0502
       0.20    0.310252    1.511597    0.382018      1.2338
       0.30    0.457816    1.433822    0.497736      1.6076
       0.40    0.595783    1.318967    0.644506      2.0816
       0.45    0.659963    1.246437    0.693596      2.2402
   the restoring force weakens and the disturbance strengthens at the same time, so
   once the error is a third of a symbol out there is no stabilising mechanism left.
   A fixed-barrier Gaussian crossing model has neither effect in it.

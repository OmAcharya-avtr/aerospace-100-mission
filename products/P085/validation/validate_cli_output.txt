3. every cache directory in the tree is covered by .gitignore
==============================================================================
A cache directory is not itself a defect: the test runner and the
interpreter create them and .gitignore excludes them. What IS a defect is
one that .gitignore does not cover, because it then reaches a commit and
the release gate fails a tracked build artifact.

Coverage is read from .gitignore the way git reads it. A pattern with no
slash matches at ANY depth; a pattern with a leading slash matches only at
the repository root. That distinction is the P060 defect of this mission,
where a bare junit.xml in a product .gitignore silently excluded a required
committed fixture several directories down.

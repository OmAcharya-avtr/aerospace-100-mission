# Dataset card — ConstelLink synthetic link-availability dataset

## Summary

A synthetic dataset of satellite contact opportunities, each labelled with
whether the contact closed at its planned data rate. It exists to compare
three link-availability predictors on identical splits. It is **not** a record
of observed link behaviour and must not be used as one.

Generated by `src/constellink/synthdata.py`. Nothing is committed to the
repository: the dataset is regenerated deterministically from a seed, and the
default configuration produces 1974 rows in about 7.8 s on one CPU core.

```python
from constellink.synthdata import DatasetConfig, generate_dataset
data = generate_dataset(DatasetConfig(horizon_hours=18.0, seed=20260401))
```

## What is real and what is generated

| part | status |
|---|---|
| orbital geometry | **real computation** — `sgp4` propagation of a Walker shell, exact contact-window geometry |
| elevation, slant range, window duration | **real computation**, derived from that geometry |
| ground-station coordinates | real places, rounded to 0.01 deg, used only to produce varied pass geometry |
| weather state | **generated** from parametric distributions chosen by the author |
| pointing error | **generated**, half-normal with a 3 urad scale |
| scintillation fade | **generated**, log-normal in intensity |
| the label | **generated** by this package's own capacity models |

The last row is the important one. The label is produced by evaluating
`constellink.capacity` on the generated latent state and comparing with a
planned rate. A model trained on this dataset is learning this package's
capacity model plus the observation noise placed in front of it. That is a
self-consistency exercise. It demonstrates a comparison *method*, not an
agreement with reality.

## Generative process

Per contact, with `numpy.random.default_rng(seed)`:

1. **Latent cloud optical depth** `tau` from a Gamma distribution whose mean is
   set by the station's assigned climate regime; **latent visibility** from a
   log-normal anti-correlated with `tau`. Inter-satellite links are above the
   atmosphere and get the clear-sky sentinel (`tau = 0`, visibility 100 km).
2. **Latent pointing error**, half-normal, 3 urad scale.
3. **Latent scintillation fade** in dB, log-normal in intensity (Gaussian in
   dB). This term is deliberately **not** exposed as a feature, so it is
   irreducible aleatoric noise and no predictor can reach perfect accuracy.
   Log-normal is the conventional weak-fluctuation model for intensity
   scintillation (Andrews & Phillips 2005, *Laser Beam Propagation through
   Random Media*, 2nd ed., SPIE Press, Ch. 9).
4. **Achievable rate** from `constellink.capacity` with those realisations,
   compared with the **planned rate** for the link class.
5. **Features** are noisy observations of the latent state, multiplied by
   log-normal noise with `obs_noise_scale = 0.35` — a forecast is not a
   measurement, so there is a genuine information gap between what a predictor
   sees and what determines the label.

### How the planned rate is defined, and why it was not tuned

The planned rate is the clear-sky, zero-pointing-error achievable rate of the
same terminal at the **worst-case range of that link class**: the maximum
supported ISL range (5000 km), or the slant range at the elevation mask for a
ground leg. A contact "closes" when the realised geometry and weather beat
what the worst-case plan assumed.

This matters. Choosing a fixed threshold rate and tuning it until the classes
balanced would have made the subsequent calibration comparison meaningless.
The plan here is a function of the terminal definitions and the geometry
alone, with a `plan_backoff_db` of 0 by default. The resulting base rate,
0.7523, is what fell out.

| link class | planned rate |
|---|---|
| RF, inter-satellite | 13.7 Mbit/s |
| RF, ground | 104.0 Mbit/s |
| optical, inter-satellite | 996.4 Mbit/s |
| optical, ground | 7556.3 Mbit/s |

## Composition (default configuration)

| property | value |
|---|---|
| rows | 1974 |
| base rate (fraction closed) | 0.7523 |
| ground-leg rows | 328 |
| inter-satellite rows | 1646 |
| optical rows | about half, by a Bernoulli draw at `optical_fraction = 0.5` |
| distinct links (grouping key) | 168 |
| strata | 8 occupied of 12 possible |

Per-stratum closure rates in the default configuration run from 0.075 (optical
ground legs at 10-25 deg elevation) to 1.000 (ground legs above 50 deg). Two
strata are degenerate at 1.0: high-elevation ground legs always close, which
is a real consequence of the geometry, not a labelling artefact.

The dataset is **inter-satellite dominated**, because a 24-satellite shell has
276 satellite pairs and only 120 satellite-station pairs. The weather story
lives in the 328 ground rows. A reader who wants the weather signal to
dominate should raise the station count or lower `isl_max_range_km`.

## Features

Index order is part of the contract (`constellink.synthdata.FEATURE_NAMES`).

| # | name | units | source |
|---|---|---|---|
| 0 | `climatology_prior` | — | the stratum's base rate; the climatology baseline's only input |
| 1 | `max_elevation_deg` | deg | real geometry; 90 for an ISL |
| 2 | `min_range_km` | km | real geometry |
| 3 | `duration_s` | s | real geometry |
| 4 | `cloud_optical_depth_obs` | — | noisy observation of latent `tau` |
| 5 | `visibility_km_obs` | km | noisy observation of latent visibility |
| 6 | `pointing_jitter_urad_obs` | urad | noisy observation of the latent pointing error |
| 7 | `is_optical` | 0/1 | terminal assignment |
| 8 | `is_ground` | 0/1 | link kind |

Label: 1 if the realised achievable rate met the planned rate for the link
class, else 0.

Group key: `"<node_a>|<node_b>"`, used by `grouped_split` so no link appears on
both sides of a split.

## Splits

`grouped_split` partitions by **link**, not by row. Row-wise splitting leaks:
contacts of the same link share geometry and station climate, and a model can
memorise the link instead of learning the physics. The leakage is measured
rather than asserted — `validation/validate_calibration.py` reports both
splits, and the measured optimism is +0.00249 Brier for the logistic baseline
and +0.00674 for the learned model.

`row_split` exists only to produce that measurement. It is not the split any
result is reported on.

## Known limitations

1. **Self-consistency, not ground truth.** Stated three times in this card
   because it is the only thing about this dataset that can mislead.
2. **Climate regimes are modelling choices.** `SVALBARD` is labelled "cloudy"
   and `SANTIAGO` "clear" because the comparison needs varied weather, not
   because those are published climatologies for those sites.
3. **The RF cloud term is a proxy.** Ka-band excess attenuation is taken as
   `0.3 + 0.4 tau` dB at zenith. That is a linear proxy for the latent optical
   depth, not an ITU-R cloud-attenuation model.
4. **The optical boundary layer is a round number.** A 2 km equivalent zenith
   path length is assumed when converting the Kim-Kruse specific attenuation
   to a zenith attenuation.
5. **Independent draws.** Weather at different stations and at different times
   is drawn independently. Real weather is correlated in both, so the dataset
   understates the difficulty of forecasting a correlated outage.
6. **No diurnal or seasonal cycle.** The horizon is 18 h and the climatology
   is static.
7. **No equipment failures, no scheduling conflicts, no interference.** Every
   non-closure in this dataset is a propagation or geometry event.

## Reproducibility

```bash
python -c "from constellink.synthdata import *; d = generate_dataset(DatasetConfig()); print(len(d), d.base_rate)"
# 1974 0.7522796352583586
```

Pinned in `tests/test_regression.py` at a smaller 6 h, seed 7 configuration:
673 rows, base rate 0.757800892, feature sum 2258980.6921.

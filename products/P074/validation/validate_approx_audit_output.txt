why this audit exists
==============================================================================
  pytest.approx(expected, rel=r) carries a DEFAULT ABSOLUTE TOLERANCE of
  1e-12 and passes when EITHER bound is satisfied. For a quantity of order
  1e-5, every relative tolerance tighter than 1e-7 is therefore silently
  replaced by the absolute one. Conservation residuals in this product are
  of order 1e-9, so an assertion on one with rel=1e-6 and no explicit abs
  would be testing |x - y| < 1e-12, which it would pass for any pair of
  numbers that small.

==============================================================================
executed audit
==============================================================================
  Three experiments, each on a copy of the whole test tree in a temporary
  directory. They answer different questions and conflating them is the
  reason the first version of this script reported a misleading number.

  (a) force_zero_where_absent : add abs=0.0 only where no abs= is
      declared. Those are the ONLY calls the 1e-12 default applies to, so
      this is the experiment that measures reliance on it. The static scan
      above found no such call, so the set is empty and the run is
      skipped: the measurement is zero by construction and saying so is
      more honest than spending 80 s to print it.
  (b) force_zero_everywhere   : set abs=0.0 on every rel= call, overriding
      the explicit ones. This is the literal substitution the mission
      brief asks for. What it measures is which assertions have a
      LOAD-BEARING absolute tolerance -- that is, exactly the set where
      the 1e-12 default would have been the wrong tolerance.
  (c) strip_abs               : remove the explicit abs= so the 1e-12
      default applies. This measures what the explicit declarations are
      protecting, which is the counterfactual for a suite that had not
      written them.

  experiment                  calls rewritten   tests  failures  errors  elements
  baseline                                 0     273         0       0       273
  force_zero_everywhere                   67     273        17       0       273
  strip_abs                               67     273        10       0       273

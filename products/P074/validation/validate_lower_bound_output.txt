==============================================================================
  A perfect model compared against a bad one gives a large D and an error

  but the smaller error is below it, which is why README.md does not claim
  the bound applies to the element set the user holds.

negative control: the inequality written the wrong way round
==============================================================================
  If the bound were D rather than D/2, it would claim max(|e1|, |e2|) >= D,
  which is false whenever the two errors are comparable. The control shows
  it failing, which is what makes the passing result above evidence.

  samples                       : 401
  violations with the bound D   : 401
  violations with the bound D/2 : 0
  [PASS] the wrong-way-round bound is violated (control fires) -- 401 of 401 samples
  [PASS] the correct bound is not violated on the same data -- 0 of 401 samples

  The two models here are offset in opposite directions by 1 km, so their
  errors are each about half the separation and the D-bound fails at
  almost every sample. This is the equality case of the triangle
  inequality, which is exactly where a factor of two matters.

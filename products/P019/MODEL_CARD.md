## 1. Problem

Predict the **vertical profile of the refractive-index structure parameter
Cn²(h)**, from the surface to 20 km, from surface meteorology that a site
already measures: air temperature, wind speed, relative humidity, time of day,
and day of year.

* Task: regression, target `log10 Cn²` (Cn² in m^-2/3), one scalar per
  (scenario, altitude) pair, plus an interval.
* Working in log10 is not cosmetic: Cn² spans about seven decades over the
  column, so a linear-space loss would fit the ground layer and ignore
  everything above it.
* Why anyone wants this: r₀, θ₀ and the Greenwood frequency — the numbers that
  size an adaptive-optics system or an optical link budget — are integrals of
  Cn²(h) with different altitude weights. A single climatological curve gives one
  answer for every night of the year.

## 2. Baseline (implemented FIRST, and the benchmark reference)

`cncast.baselines` was written and validated before any model was fitted. It
contains:

* **`hufnagel_valley(h, v, A)`** — Hufnagel (1974) / Valley (1980), form as
  Andrews & Phillips (2005) Eq. 12.30. Validity 0–20 km AGL.
* **`hv57(h)`** — the HV 5/7 parameterisation (v = 21 m/s, A = 1.7e-14 m^-2/3).
  **This is the mandated baseline.** Verified to reproduce its defining
  property: r₀ = 4.9624 cm (nominal 5 cm, −0.75 %) and θ₀ = 7.0109 µrad
  (nominal 7 µrad, +0.16 %) at 500 nm, zenith
  (`validation/VALIDATION.md` §1.2).
* **`slc_day` / `slc_night`** — Beland (1993) piecewise fits at the AMOS site,
  validity 0–20.5 km / 0–20 km above the site, each branch verified against its
  closed form to 0 relative error (§1.3). The published SLC-Day fit is
  discontinuous by +31 % at 240 m; that is reported, not smoothed over.
* **`bufton_wind` / `rms_high_altitude_wind`** — Bufton (1973) wind profile and
  the 5–20 km rms used by the H-V high-altitude term.

Two further comparators are scored alongside HV 5/7 so the learned model is
never flattered by a single weak reference:

* `SlcBaseline` — SLC-Day/Night switched on hour of day (reacts to one input).
* `ClimatologyBaseline` — the mean training profile in altitude bins. Uses no
  weather at all and is the honest "do nothing clever" reference.

**Every one of these is a climatological model, not a forecast.** They describe
an average condition for a site or season. HV 5/7 was never designed to
condition on today's weather, which is exactly the task it is scored on in §7.

## 3. Architecture

Three `sklearn.ensemble.GradientBoostingRegressor` instances sharing
hyperparameters (`n_estimators=300`, `max_depth=4`, `learning_rate=0.06`,
`min_samples_leaf=20`, `random_state=7`):

| sub-model | loss | α | role |
|---|---|---|---|
| `median_model` | quantile | 0.50 | point prediction |
| `lower_model` | quantile | 0.05 | interval lower bound |
| `upper_model` | quantile | 0.95 | interval upper bound |

plus a scalar **conformal offset δ** fitted on a disjoint calibration split
(§9). Prediction returns `(10^lower, 10^median, 10^upper)`; because `10^x` is
monotone, log-space quantiles are exactly linear-space quantiles.

Quantile crossing (lower > upper at some query) is possible with independently
fitted quantile models. It is detected and repaired by sorting the triple
pointwise; the crossing rate on the fit set is reported by `fit_report()` and was
**0.0000** in the production run.

Inputs are the 8 columns of `cncast.dataset.FEATURE_NAMES`; no scaling is
applied (tree ensembles are scale-invariant). Pickled model size 1.79 MB
(measured); no model artefact is committed — the model is re-fitted in 16 s.

## 4. Dataset source

`DATASET_CARD.md`, generated by `src/cncast/dataset.py`. 700 scenarios ×
28 altitudes, master seed 20260807. Nothing is committed as data; regeneration
is deterministic.

## 5. Dataset limitations

**The training data is synthetic, derived from the baseline models plus
physically-motivated perturbations. Measured accuracy therefore reflects
fidelity to a generative process, not agreement with radiosonde or
scintillometer measurements.** No measured Cn² of any kind appears anywhere in
this product.

Explicitly not modelled: real boundary-layer dynamics (no surface energy
balance, no Monin-Obukhov similarity, no morning/evening transition), terrain
effects (no orography, slope flows, mountain waves or dome seeing), inversion
layers and the thin intense turbulent caps that sit on them, and jet-stream
variability (a single climatological Bufton profile with one seasonal scaling).
Also absent: synoptic weather, cloud, and any time correlation between
scenarios — so nothing here can be validated as a *forecast*.

The meteorology → Cn² coefficients have signs taken from the literature and
magnitudes chosen by hand. They are not fitted to observations.

## 6. Training procedure

```python
from cncast.model import train_default_model
model, artefacts = train_default_model()      # 15.9 s on 2 CPU cores
```

Steps, all deterministic:

1. `generate_scenarios(700, seed=20260807)`.
2. Scenario-level split, seed 4242 → 525 non-test / 175 test.
3. Second scenario-level split of the non-test pool, seed 4243 → 394 fit /
   131 calibration.
4. Feature tables: fit altitudes log-uniform per scenario (seed 99), calibration
   likewise (seed 100), test on a shared 28-point log grid.
5. Fit the three quantile regressors on the fit rows.
6. `model.calibrate(x_cal, y_cal)` → conformal δ = **+0.0838 dex**.

No hyperparameter search was run against the test split; the defaults were
chosen for the compute budget and left alone.

## 7. Metrics (held-out, from an actual run — `validation/benchmark_results.md`)

Errors in dex (decades of Cn²), 4 900 held-out rows from 175 unseen scenarios:

| predictor | RMSE | MAE | bias | p95 abs err |
|---|---:|---:|---:|---:|
| **CnCast learned model** | **0.2095** | 0.1620 | −0.0201 | 0.4190 |
| **HV 5/7 (mandated baseline)** | 0.5665 | 0.4475 | +0.2686 | 1.1048 |
| SLC day/night | 0.7314 | 0.5199 | −0.0893 | 1.2224 |
| Training climatology | 0.3102 | 0.2395 | +0.0049 | 0.6168 |

Learned/HV 5/7 RMSE ratio **0.370** (63 % reduction). Per-altitude-band tables
are in `validation/VALIDATION.md` §4.

### Honest reading of this result

The learned model wins, **and the win is close to tautological.** The targets are
generated from the H-V family with the ground-layer strength and pseudowind
driven by the very surface variables the model is given. Any method that
recovers that mapping must beat a fixed curve with no meteorological inputs.
HV 5/7 is not a strawman — it is being scored on a task it was never designed
for.

The informative comparison is against the training climatology (0.3102 dex),
the strongest non-learned predictor: the model improves on it by 32 %, which
measures how much of the generator's meteorological signal was recovered. In the
300–2 000 m band the learned model (0.2089) and the plain climatology (0.2105)
are indistinguishable — the features carry almost no information there, and that
is reported rather than omitted.

If the baseline had won, that would have been an acceptable and reportable
outcome. It did not, for the structural reason given above.

## 8. Test-split strategy

**Grouped by scenario, never by row.** All 28 rows of one profile share the five
meteorological features and the same latent layer and noise phases; a row-level
random split would place near-duplicates on both sides of the boundary and
inflate every metric. Three disjoint scenario sets: fit (394), conformal
calibration (131), test (175). The calibration set is disjoint from the test set,
which is what makes the conformal coverage claim in §9 meaningful.

What the split does **not** test: generalisation outside the training domain.
That is handled by the `extrapolating` flag, not by a metric.

## 9. Uncertainty / confidence output

Every prediction is a `ProfilePrediction` carrying `cn2_lower`, `cn2`,
`cn2_upper`, the nominal `coverage`, and an `extrapolating` flag — the model
never returns a bare point estimate.

The interval is a conditional-quantile interval (not a Gaussian bolted onto a
point estimate), conformalised by split CQR (Romano, Patterson & Candès, 2019,
*Conformalized Quantile Regression*, NeurIPS 32):

| interval | nominal | empirical coverage on held-out data | mean width |
|---|---:|---:|---:|
| raw quantile GBR | 0.900 | 0.8033 | 0.5575 dex |
| conformally calibrated | 0.900 | **0.8988** | 0.7249 dex |

Coverage stays within ±0.02 of nominal in all five altitude bands
(`validation/VALIDATION.md` §6).

Caveats: conformal coverage is *marginal*, not conditional — it is guaranteed in
aggregate, not for any chosen sub-population. Its exchangeability assumption
holds here **by construction**, because calibration and test data come from the
same synthetic generator; that is precisely why the guarantee does not transfer
to the real atmosphere. And the r₀ band obtained by integrating the two Cn²
bounds over-covers (98.9 % against a nominal 90 %) because the bounds are
perfectly correlated across altitude; treat it as an upper bound on the
uncertainty, not a calibrated interval.

## 10. Failure cases

1. **Out-of-domain weather.** Outside the training ranges (T ∉ [−10, 38] °C,
   wind ∉ [0, 14] m/s, RH ∉ [10, 95] %, h ∉ [5, 20 000] m) the tree ensemble
   returns its edge value with unchanged interval width, i.e. it is confidently
   wrong. `extrapolating=True` is set; callers must check it.
2. **The interval is not calibrated for real turbulence.** See §9.
3. **Piecewise-constant in altitude.** Gradient boosting on trees produces a
   staircase; predicted profiles have small steps and are not smooth. Derived
   integrals are affected at the sub-per-cent level on a 24-point log grid, but
   the profile should not be differentiated.
4. **No thin layers.** The model cannot produce a 30 m-thick intense layer,
   because the generator contains none. Real profiles have them, and they can
   dominate θ₀.
5. **Under-dispersion at the ends of the column.** Coverage in the 5–50 m and
   8–20 km bands is 0.882 against 0.900 nominal.
6. **Regression to the mean in derived quantities.** In
   `examples/r0_comparison.py` the predicted r₀ carries a +0.67 cm mean bias over
   175 held-out scenarios: low-r₀ (strong turbulence) cases are predicted too
   optimistically. For a link-margin calculation that is the unsafe direction.
7. **No forecast horizon.** Inputs and target are simultaneous. The model does
   not predict forward in time; the name "CnCast" refers to profile *casting*
   from surface data, not to a time forecast.
8. **Single-site assumption.** No latitude, elevation, or site descriptor is an
   input, so all sites look identical to the model.

## 11. Reproducibility (exact commands + seeds)

```bash
cd products/P019
python -m pytest tests/ -q                                  # 112 passed
ruff check src/ tests/                                      # clean
python validation/validate_baselines.py > validation/validate_baselines_output.txt
python validation/benchmark_ml.py       > validation/benchmark_results.md
python examples/profile_with_intervals.py                   # -> screenshots/
python examples/r0_comparison.py                            # -> screenshots/
python -m cncast baseline --model hv57
python -m cncast predict --temp-c 22 --wind-m-s 4 --rh-pct 45 --hour 14 --day-of-year 200
```

Seeds: data 20260807; fit altitudes 99; calibration altitudes 100; splits 4242
(and 4243 for the calibration split, derived as `split_seed + 1`); all three
regressors `random_state=7`. Verified in this session: re-running
`train_default_model()` gives identical test features, a max prediction
difference of **0.000e+00 dex**, and an identical conformal δ.

Environment: Python 3.11.15, numpy 2.4.4, scikit-learn 1.8.0,
Linux-6.18.5-fc-v18-x86_64. Exact bit-reproducibility is claimed only for the
same library versions.

## 13. Ethical / safety limits

* **Not for operational use.** Not flight-qualified, not certified, not approved
  for operational aerospace use, and not to be used for go/no-go decisions on a
  laser link, an observing run, or any hardware in the field.
* **Do not present its numbers as measurements.** Any figure, table or downstream
  number derived from this model must carry the synthetic-data caveat.
* **Directional-risk asymmetry.** The r₀ bias in §10.6 is optimistic — it
  under-predicts strong turbulence. Anyone using this for a margin calculation
  would be biased toward under-sizing. Use the interval, not the median.
* **No dual-use content.** The model contains no personal data, no controlled
  technical data, and no site-specific information.
* **Provenance.** All physics is from published, citable literature; all data is
  from a committed script. No citation, coefficient or measurement in this
  product was invented to fill a gap; where a number is hand-chosen it says so.

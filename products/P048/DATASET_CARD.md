# Dataset card — softdecode

**Status: TESTING** · Validation level 2 (research grade) · Apache-2.0 ·
© 2026 OPTIMA Organisation

All data in this repository is **synthetic**, generated by committed code from
committed seeds. No measured link data, no telemetry, no third-party dataset,
and nothing derived from a real optical terminal is used anywhere.

## What the data is

One record is **one channel bit** of an on-off-keyed optical link:

| field | meaning | units |
|---|---|---|
| `codeword` | transmitted channel bit | 0/1 |
| `h` | true normalised irradiance | dimensionless, `E[h] = 1` |
| `h_hat` | the receiver's estimate of `h` | dimensionless |
| `y` | matched-filter sample, `a h c + n` | electrical units, `sigma = 1` |

Records are grouped into LDPC codewords of 96 channel bits carrying 50
information bits.

## How it is generated

`softdecode.simulate.simulate_ook` draws, in this fixed order, from one
`numpy.random.default_rng(seed)`:

1. information bits, `rng.integers(0, 2, (blocks, 50))`;
2. true fading `h`, one standard normal per sample for the lognormal model, two
   gamma draws per sample for gamma-gamma;
3. the channel estimate `h_hat` from the error model — one standard normal per
   sample, or none when the jitter is zero;
4. noise, `rng.standard_normal((blocks, 96))`.

The order is part of the specification of every number in this repository: it
is what makes a bias sweep comparable, because the bits, the fading and the
noise are identical across the sweep and only the estimate changes.

## Generating models and their provenance

| component | model | source |
|---|---|---|
| fading, weak turbulence | unit-mean lognormal, `sigma_I**2 = exp(sigma_x**2) - 1` | Andrews & Phillips, *Laser Beam Propagation through Random Media*, 2nd ed., SPIE Press, 2005, ch. 9 |
| fading, weak to strong | unit-mean gamma-gamma, `sigma_I**2 = 1/a + 1/b + 1/(ab)` | Al-Habash, Andrews & Phillips, *Opt. Eng.* 40(8), 1554–1562, 2001 |
| noise | thermal-limited, signal-independent AWGN | the detection model under which Zhu & Kahn, *IEEE Trans. Commun.* 50(8), 1293–1300, 2002, derive FSO maximum-likelihood detection and its imperfect-channel-knowledge case |
| CSI error | multiplicative lognormal (bias + jitter), or a stale estimate as a correlated lognormal sample | parametric; no measured estimator is modelled |

## Splits

Three splits, disjoint by construction, from `softdecode.datasets`:

| split | seed | blocks (validation script) | use |
|---|---|---|---|
| `train` | `BASE_SEED + 0 + 1000 * round(10 * Eb/N0)` | 500 per Eb/N0 point, 5 points | fits the forest |
| `tune` | `BASE_SEED + 1 + 1000 * round(10 * Eb/N0)` | 600 | chooses every free parameter: `alpha`, `L_max`, and the forest's own output clip |
| `report` | `BASE_SEED + 2 + 1000 * round(10 * Eb/N0)` | 1500 | every published number |

`BASE_SEED = 20261006`. The splits share no channel realisation: each draws its
own bits, fading, estimates and noise from its own generator. The tuning split
exists so that the comparison between the learned corrector and the one-parameter
non-learned fixes is not rigged by tuning those parameters on the reporting data.

Training set size in the validation script: 5 Eb/N0 points × 500 blocks × 96
channel bits = **240 000 samples**, 6 features each.

## Features given to the learned corrector

Only quantities a receiver can actually compute:

`y / sigma`, `h_hat`, `log h_hat`, `a h_hat / sigma`, the plug-in LLR, and
`a / sigma`. The plug-in LLR is included deliberately: the model can then only
win by adding information the naive answer does not already carry.

The corrector is **not** given the bias, the jitter, the correlation, the
scintillation index, or the true `h`. Its only extra information over the
plug-in receiver is the transmitted bit of each training sample, i.e. pilot
bits.

## Labels

The label is the transmitted channel bit. No analytic LLR is used as a
regression target, so the corrector is not distilling a formula it is then
compared against.

## Limitations of the data

1. **Fading is independent per channel bit.** This is the ideal-interleaving
   limit. A real atmospheric channel is correlated over tens of milliseconds, so
   every coded result obtained from this data is optimistic for a real link, and
   the amount is not estimated here.
2. **The noise is signal-independent.** A shot-noise-limited receiver has
   `sigma**2` depending on the received signal, and a Poisson or
   Webb–McIntyre–Conradi count statistic. None of that is in the data.
3. **No pointing jitter, no background light variation, no detector
   nonlinearity, no timing error.** Background light is absorbed into `sigma**2`
   only to the extent that it is signal independent.
4. **The CSI error models are parametric choices, not measurements.** A real
   estimator's error is whatever its pilot structure and its loop bandwidth
   make it; the lognormal-multiplicative and correlated-lognormal forms here are
   convenient and analytically tractable, not calibrated.
5. **Nothing is committed as data.** Every array is regenerated from the seeds
   above. There is no fixed data file to audit, only the generator, which is the
   point: the generator is the dataset.
6. **One code, one length.** All coded results use the shipped length-96
   (3,6)-regular LDPC code at rate 50/96, or the extended Hamming (8,4) code for
   cross-check X3. Nothing here establishes that the margins transfer to a
   long, well-designed code.

## Regeneration

```bash
python validation/validate_corrector.py    # rebuilds all three splits and the model
python -m softdecode mismatch --blocks 400 # a smaller regeneration, same seeds
```

Both are deterministic given the seeds printed in their own output.

This data describes a model of an optical channel. It is research-grade and is
not flight-qualified, not certified, and not approved for operational aerospace
use.

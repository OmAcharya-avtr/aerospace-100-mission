# Dataset card — synthetic HARQ-over-fade episodes

**Status: TESTING** · Validation level 2 (research grade) · Apache-2.0 ·
© 2026 OPTIMA Organisation

**Every datum in this repository is synthetic.** Nothing here was measured on a
spacecraft, a ground station, a test range or any real radio. The data is
generated by committed code from a stated model, under fixed seeds, and the
only honest claim about it is that it is a faithful sample from that model.

## What the data is

An *episode* is a sequence of frames carried over one HARQ process on a link
whose signal-to-noise ratio is governed by a two-state fade. Time is counted in
rounds; one round is one transmission plus one feedback wait of `D` channel
symbol times.

A *decision row*, which is what the learned model trains on, is produced once
per round:

| column | type | meaning |
|---|---|---|
| `features` | float64 × 8 | the observable state, `arqlonghaul.policy.FEATURE_NAMES` |
| `actions` | int | index into the action set `{10, 25, 50, 100, 200}` symbols |
| `cost` | float64 | realised cost from this decision to the end of the frame, symbol times |

The `cost` target includes the drop penalty if the frame ends undecoded, so it
is the quantity the policy is asked to minimise and not a proxy for it.

## Generating process, stated in full

Fade state: a two-state Markov chain on the round index, the Gilbert-Elliott
construction of `arqlonghaul.channel` (E. N. Gilbert, *Capacity of a burst-noise
channel*, Bell System Technical Journal 39(5):1253–1265, 1960; E. O. Elliott,
*Estimates of error rates for codes on burst-noise channels*, BSTJ
42(5):1977–1997, 1963).

Per-symbol error probability: coherent BPSK over additive white Gaussian noise,
`p_b = 0.5 erfc(sqrt(Es/N0))`, evaluated at the Es/N0 of the current state.

Decoding: a bounded-distance decoder over the accumulated word. Symbol errors
accumulate as a sum of binomials over the per-round segments, and the frame
decodes at round `m` when the accumulated error count is at most
`t_m = floor(alpha (n_m - k) / 2)`, the Singleton bound scaled by an explicit
code-family efficiency `alpha`.

| parameter | value | note |
|---|---|---|
| `k` | 200 | information symbols per frame |
| `alpha` | 0.5 | code-family efficiency; 1.0 would be the MDS limit |
| `esn0_good_db` | +2.5 | per-symbol Es/N0 in the unfaded state |
| `esn0_bad_db` | −1.5 | per-symbol Es/N0 in the faded state |
| `rtt_symbols` (D) | 50 | feedback latency charged after every round |
| `max_rounds` (M) | 4 | transmissions allowed per frame |
| `drop_penalty` | 2000 | symbol times charged for an undecoded frame |
| `actions` | 10, 25, 50, 100, 200 | redundancy increment, symbols |
| `pi_bad` | 0.20 | stationary faded duty cycle, both regimes |

Derived: `ber_good = 0.029655`, `ber_bad = 0.117040`, stationary mixture
`ber_mixture = 0.047132`. The mixture is identical in both regimes by
construction, so the two differ only in correlation time.

| regime | `p_gb` | `p_bg` | mean faded sojourn | autocorrelation 1/e time |
|---|---|---|---|---|
| long-burst | 0.01 | 0.04 | 25 rounds | 19.50 rounds |
| short-burst | 0.16667 | 0.66667 | 1.5 rounds | 0.56 rounds |

## Size, and why it is not committed

| split | seeds | frames per seed | frames | decision rows |
|---|---|---|---|---|
| fit | 1000–1119 (120) | 150 | 18000 | 18330 (long-burst) |
| tune | 2000–2039 (40) | 120 | 4800 | per grid point |
| report | 3000–3299 (300) | 150 | 45000 | not used for fitting |

No episode data is committed. It is regenerated deterministically in a second
or two by `arqlonghaul.policy.collect_transitions`, which is cheaper than
storing it and cannot drift from the code that defines it. What *is* committed
is the two `.npz` policy tables, 8 and 11 kB, described in `MODEL_CARD.md`.

## Seed discipline

`arqlonghaul.datasets.SEED_SPLIT` holds three disjoint seed tuples and its
constructor raises `ValueError` if they overlap. Within an episode the seed
drives both the fade trace and the symbol-error draws, and the fade trace is
generated up front, so two policies run on the same seed see the same channel
until their round counts diverge. That is common random numbers, and it is what
makes a one per cent difference between two policies measurable at 45000
frames.

## Limitations of the data, which are the limitations of the model behind it

- **Two states.** A real fade has a continuous depth distribution and a
  frequency-selective structure. Two states with fixed Es/N0 values is the
  coarsest model that produces correlated errors at all, which is why it is
  here and why no quantitative result from it should be read as a prediction
  about a real link.
- **Geometric sojourns.** A two-state Markov chain gives exponentially
  distributed fade durations. Rain fade, scintillation and antenna-pointing
  events are not exponential.
- **The code is a bound, not a code.** `t_m = floor(alpha (n_m - k)/2)` with
  `alpha = 0.5` is a Singleton-bound model of a rate-compatible family. It is
  not an LDPC, turbo or Reed-Solomon code and no claim is made that it matches
  one. Results scale with `alpha`, and `validation/validate_harq.py` reports
  that sensitivity explicitly: the retransmit/redundancy crossover moves by
  −42.7 per cent at `alpha = 0.4` and +86.8 per cent at `alpha = 0.8`.
- **Symbol errors independent within a round.** The fade is correlated across
  rounds but the symbol errors inside one transmission are independent, which
  means this data contains no intra-frame burst structure and therefore nothing
  about interleaver depth.
- **Perfect, error-free, zero-cost feedback.** Acknowledgements are never lost
  and never corrupted. On a real asymmetric space link the return channel is
  the weaker one.
- **No Doppler, no pointing loss, no amplifier nonlinearity, no coding gain
  from anything but the modelled parity.**
- **One HARQ process, no pipelining.** The feedback wait `D` is charged after
  every round. A real sender with several parallel processes would hide it, and
  every goodput figure here would change.
- **Nominal link geometry.** The round-trip times in
  `arqlonghaul.link.PRESETS` are two-way light time for a round nominal range
  plus a stated processing allowance. They put `N` in the right decade. They
  are not ephemeris values and they are labelled as illustrative wherever they
  appear.

## Intended use

Studying how ARQ and HARQ behave when the round trip dominates, and how wrong
the independent-error textbook expressions are when errors are correlated.
Teaching. Sizing a *study*, not a mission.

## Out-of-scope use

Any use where the number matters operationally. This dataset cannot support a
link budget, a buffer procurement, a protocol selection for flight, or a
reliability case. It is research-grade and it is not flight-qualified, not
certified, and not approved for operational aerospace use.

## Reproducing the data

```bash
python -c "
from arqlonghaul.datasets import SEED_SPLIT, long_burst_env
from arqlonghaul.policy import collect_transitions
tr = collect_transitions(long_burst_env(), SEED_SPLIT.fit[:120], 150, rng_seed=7)
print(tr['features'].shape, tr['cost'].mean())
"
python validation/export_policy_table.py   # prints array SHA-256 and versions
```

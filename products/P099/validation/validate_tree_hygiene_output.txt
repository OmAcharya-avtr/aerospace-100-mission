2. THIS SCRIPT'S OWN INTERPRETER
==============================================================================
a validation script in another product of this mission imported its own
package to call it, which wrote 11 .pyc files into the tree, and then
scanned the tree for exactly those files and failed itself. Setting
PYTHONDONTWRITEBYTECODE for SPAWNED subprocesses does nothing about that:
the polluting interpreter is the script's own. Hence
sys.dont_write_bytecode = True as the first statement after the __future__
import in every runnable script here, which cannot be delegated to
_bootstrap because CPython writes a module's bytecode cache BEFORE
executing that module.

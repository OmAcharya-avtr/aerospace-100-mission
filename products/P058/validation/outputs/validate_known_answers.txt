1. CUSUM ARL0 against the NIST handbook and Siegmund's formula
------------------------------------------------------------------------------
  Source 1: NIST/SEMATECH e-Handbook of Statistical Methods, section
            6.3.2.3.1, 'Cusum Average Run Length',
            https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc3231.htm
            read 2026-10-10. For k = 0.5 it tabulates the ONE-SIDED
            in-control ARL as 336 at h = 4 and 930 at h = 5. The page
            states: 'If one has to control both positive and negative
            deviations, as is usually the case, two one-sided charts are
            used'. The handbook credits no external author for the table.
  Source 2: Siegmund's closed form, ARL = (exp(-2 D b) + 2 D b - 1)/(2 D^2)
            with b = h + 1.166 and D = delta - k.

  This package's CUSUM runs BOTH one-sided charts against the same h, so
  it false-alarms at twice the rate and the reference is the handbook
  value HALVED. Quoting 336 for a two-sided chart would be wrong by a
  factor of two, which is the error this section exists to prevent.

  h = 4: handbook one-sided   336.0   Siegmund  338.09   relative difference 0.62 %
  PASS  the two references agree within 1 % at h = 4  [0.62 %]
  h = 5: handbook one-sided   930.0   Siegmund  938.22   relative difference 0.88 %
  PASS  the two references agree within 1 % at h = 5  [0.88 %]

  Measured, 12 seeds x 60000 stationary samples = 720000 samples per h.

  h    reference   measured      SEM   rel.diff   runs   censored tail
  4        168.0      164.6      2.5     -2.0 %   4366      0.17 %
  PASS  measured two-sided CUSUM ARL0 within 10 % of the halved handbook value at h = 4  [measured 164.6 +/- 2.5 vs reference 168, -2.0 %]
  PASS  measured ARL0 is below the reference at h = 4, as the censored-tail exclusion predicts  [-2.0 %]
  5        465.0      458.5     11.8     -1.4 %   1560      0.65 %
  PASS  measured two-sided CUSUM ARL0 within 10 % of the halved handbook value at h = 5  [measured 458.5 +/- 11.8 vs reference 465, -1.4 %]
  PASS  measured ARL0 is below the reference at h = 5, as the censored-tail exclusion predicts  [-1.4 %]

  The tolerance is 10 % and was set from the Monte Carlo standard error
  before the measurement, not after it: at these budgets the relative
  SEM is 1.5-2.6 %, so 10 % is four to seven standard errors. The halving
  is itself an approximation - the two arms are driven by the same
  observations and are not independent - which is why the band is not
  tighter.

5. ADWIN cut rule, hand-computed
------------------------------------------------------------------------------
  Transcribed from Bifet and Gavalda's technical report 'Adaptive
  Parameter-free Learning from Evolving Data Streams' section 4.1.1
  (upcommons.upc.edu), the author-hosted source this session could read:

      m       = 2 / (1/|W0| + 1/|W1|)
      eps_cut = sqrt( (1 / (2 m)) * ln(4 |W| / delta) )

  With |W0| = |W1| = 10, |W| = 20, delta = 0.05:
      m       = 2 / (1/10 + 1/10) = 10
      eps_cut = sqrt( 0.05 * ln(1600) ) = sqrt(0.05 * 7.3777589)
              = sqrt(0.36888794) = 0.60736146
  recomputed here: 0.60736146
  PASS  hand arithmetic reproduces the formula  [0.60736146]
  detector on 10 zeros then 10 tens: cut declared = True, cut evidence = 16.4647 (ratio to eps_cut)
  PASS  the implementation cuts on a 10-sigma split

  NOTE, recorded rather than resolved: the SDM 2007 paper is widely
  quoted with m = 1/(1/n0 + 1/n1), a factor of two smaller, which makes
  eps_cut larger by sqrt(2). This package implements the harmonic-mean
  form above because that is what the source it could verify states, and
  calibrates delta to a measured ARL0, which absorbs a constant factor on
  eps_cut exactly. No number in this repository depends on which form is
  meant, because none of them uses the nominal delta as a false-alarm
  rate.
  FINDING  ADWIN cut rule: the verified author-hosted source states m = 2/(1/n0+1/n1); the SDM 2007 paper is widely quoted with m = 1/(1/n0+1/n1). Implemented as verified; delta is calibrated so the factor is absorbed.

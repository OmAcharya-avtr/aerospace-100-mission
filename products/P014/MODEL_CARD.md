# Model Card — wavelab `ZernikeSlopeEnsemble` 0.1.0

**Model:** ensemble of 5 scikit-learn `MLPRegressor` networks mapping a
(possibly subaperture-dropout-masked) Shack-Hartmann-style slope vector to
Noll-Zernike coefficients, with a per-coefficient ensemble-spread confidence
output.
**Status:** TESTING · **Validation level:** 2 (Research) · **License:**
Apache-2.0
**Product:** P014 WaveLab, OPTIMA aerospace portfolio.

> **This model is not certified for operational flight use.**

> ## Read this before using the model
>
> On the measured benchmark (`validation/validate_dropout.py`, raw output
> `validation/dropout_output.txt`), the regularized least-squares baseline
> (`ModalReconstructor`) **beats the learned ensemble at 9 of 10 tested
> operating points**, by a widening margin as photon flux increases (1.2x at
> flux 100, growing to **7.4x at flux 10 000**). The learned ensemble wins
> exactly **one** point: at 60% subaperture dropout, where the baseline's
> fixed Tikhonov regularization becomes unstable on a severely
> under-determined system (RMS error 0.82 rad, effectively unusable) while the
> learned ensemble stays smooth (RMS error 0.060 rad, a **13.5x** advantage
> at that one point). This is the measured result, not a tuned one; do not
> read it as a general "ML wins under dropout" result -- the crossover here
> is a specific baseline failure mode at extreme dropout with a fixed
> regularization parameter, not a broad regime of ML superiority.

---

## 1. Problem

Given a Shack-Hartmann-style wavefront-slope vector (subaperture-centre
gradients, `wavelab.zernike.zernike_slope_matrix` convention), predict the
Noll-Zernike coefficients (piston excluded) of the wavefront that produced
it, together with a per-coefficient confidence.

- **Input:** `(2 * n_sub,)` slopes (x-block then y-block; zero at any
  subaperture flagged inactive) concatenated with an `(n_sub,)` active/dropout
  mask -- `(3 * n_sub,)` total. Default geometry: `n_sub = 32`.
- **Output:** `(n_modes,)` Noll coefficients [rad] (default 14 modes, Noll
  `j = 2..15`), plus an optional per-coefficient ensemble standard deviation.

## 2. Baseline -- implemented first, benchmarked on identical held-out data

Per the mission rule, the classical reconstructor comes first:
`wavelab.modal.ModalReconstructor`, a Tikhonov- or truncated-SVD-regularized
least-squares solve of the analytic Zernike gradient interaction matrix
(Southwell 1980, *J. Opt. Soc. Am.* **70**, 998, for slope-to-phase geometries
generally). It was implemented and validated for noise-free recovery and
photon-noise propagation (`validation/validate_noise_free.py`,
`validation/validate_photon_noise.py`) *before* this model was written. Every
ML number below is measured on the same held-out batches as the baseline,
generated by the identical `wavelab.dataset.generate_batch` call.

## 3. Architecture

- **Features** (`ZernikeSlopeEnsemble.features`): the `2 * n_sub` slope
  values (zero at dropped subapertures) concatenated with the `n_sub`-length
  active/dropout mask (1.0 = active, 0.0 = dropped), so "measured zero" and
  "not measured" are distinguishable inputs.
- **Members:** 5 x `MLPRegressor(hidden_layer_sizes=(64, 32))`, ReLU, Adam,
  `alpha=1e-3`, `max_iter=300`, `early_stopping=True`, `n_iter_no_change=12`,
  `validation_fraction=0.1`, seeds `random_state + k` for `k = 0..4`.
- **Targets:** Noll-Zernike coefficients directly [rad], no rescaling.
- **Prediction:** member mean; `return_std=True` adds the member standard
  deviation (Lakshminarayanan, Pritzel & Blundell, *NeurIPS 30*, 2017, deep
  ensembles).

**Deviation from what one would ideally build.** PyTorch is not available in
this build environment, so a graph- or attention-based architecture that
could exploit the subaperture layout's geometry is not an option; a fully
connected ensemble is used instead, with no structural knowledge of which
input slopes are spatial neighbours. This is a plausible contributor to the
model's uniformly worse performance at moderate-to-high flux reported below --
a convolutional or graph network could in principle learn the same
locality-exploiting structure the analytic interaction matrix already encodes
exactly, at the cost of learning it approximately from finite data instead of
having it exactly by construction.

## 4. Dataset

Full card: [`DATASET_CARD.md`](DATASET_CARD.md). Summary: 100% synthetic,
generated from `wavelab.screens.kolmogorov_screen` (Kolmogorov PSD, FFT
method) fitted to Zernike coefficients, with an analytic forward slope model
and a shot-noise-only Gaussian noise model. Not committed (regenerates in a
few seconds per thousand samples); deterministic given a seed.

## 5. Training procedure

```bash
cd products/P014

```

| Item | Value |
|---|---|
| Training samples | 1800 |
| Training operating point | photon flux 800, subaperture dropout rate 0.25 (single fixed point, not the sweep) |
| `r0/D` | uniform, 0.10 - 0.35, per sample |
| Geometry | 8x8 subaperture layout on the unit disc -> 32 active subapertures; Noll modes `j = 2..15` (14 modes) |
| Training seed | 100 |
| Internal validation | 10% of training samples, held out by `early_stopping` |
| Hyperparameter search | **none** -- no test information entered any choice |

## 6. Test-split strategy

The split is by **disjoint RNG seed**, not by partitioning one dataset (see
`wavelab.dataset.generate_batch` docstring for the exact seed derivation):

| Set | Seed |
|---|---|
| Training | 100 |
| Held-out test, flux sweep | 9000 |
| Held-out test, dropout sweep | 9500 |

Train and test are drawn from the same generative process (`DATASET_CARD.md`
§2), so this measures **in-distribution generalization only** -- it is not a
robustness or domain-transfer test, and it says nothing about real
atmospheric turbulence or a real sensor.

RMS Zernike coefficient error [rad] over 400 held-out samples per point.
Full run: [`validation/dropout_output.txt`](validation/dropout_output.txt).

|---:|---:|---:|---:|---|
| 100 | 0.05106 | 0.06153 | 1.205 | baseline |
| 300 | 0.02948 | 0.04564 | 1.548 | baseline |
| 1000 | 0.01615 | 0.04008 | 2.483 | baseline |
| 3000 | 0.00932 | 0.03853 | 4.133 | baseline |
| 10000 | 0.00511 | 0.03802 | 7.447 | baseline |

**Sweep B -- vs subaperture dropout rate, flux = 800:**

| dropout | baseline RMS | ML RMS | ML/baseline | winner |
|---:|---:|---:|---:|---|
| 0.00 | 0.01765 | 0.04028 | 2.282 | baseline |
| 0.15 | 0.02006 | 0.03963 | 1.976 | baseline |
| 0.30 | 0.02377 | 0.04330 | 1.821 | baseline |
| 0.45 | 0.03427 | 0.05012 | 1.462 | baseline |
| 0.60 | 0.81656 | 0.06043 | 0.074 | **ML** |

**Summary: baseline wins 9/10 operating points; ML wins 1/10** (60% dropout,
where the baseline's fixed-`lambda` Tikhonov solve degrades badly on a
severely under-determined system -- see Limitations below for why, and note
this is a property of the *baseline's fixed regularization choice*, not an
inherent limit of regularized least squares in general).

## 8. Uncertainty / confidence output

`predict(slopes, active, return_std=True)` returns the per-coefficient
standard deviation across the 5 members [rad].

| Regime | measured `mean(std) / sqrt(mean(error^2))` |
|---|---|
| Flux sweep, 100 -> 10000 | 0.763 -> 0.662 |
| Dropout sweep, 0.0 -> 0.60 | 0.675 -> 0.686 (dips to 0.573 at dropout 0.30) |

**This is not a calibrated 1-sigma error bar.** The ratio is consistently
**below 1** across every tested condition (range 0.57-0.76): the ensemble
spread under-states the true RMS error by roughly 25-40% throughout, with no
regime where it over-states it. This means the ensemble members agree with
each other *more* than they agree with the truth -- a classic symptom of
shared systematic bias across members that an ensemble spread cannot detect.
It is usable as a coarse, monotonic-ish qualitative indicator at best; it
must **not** be used as a measurement covariance in a wavefront reconstructor,
Kalman filter, or closed-loop controller.

## 9. Failure cases

1. **Loses to the classical baseline almost everywhere measured**, and the
   gap widens without bound as flux increases (7.4x at flux 10 000; nothing
   in the tested range suggests this saturates). Anyone choosing between the
   two reconstructors by measured accuracy alone should default to the
   baseline except in the one confirmed regime below.
2. **The one measured ML win is a baseline failure mode, not an ML strength
   in the usual sense.** At 60% dropout with `n_sub=32`, roughly 13
   subapertures remain active on average; `ModalReconstructor`'s fixed
   `reg=3e-3` Tikhonov parameter is not adapted to the shrinking row count,
   so on the unluckier dropout draws the regularized solve becomes numerically
   unstable (mean RMS error 0.82 rad, i.e. comparable to or larger than the
   input signal itself). A baseline with dropout-adapted regularization (not
   implemented here) would likely close this gap; see README "Roadmap".
3. **Extrapolation outside the training operating point.** Trained at a
   single (flux=800, dropout=0.25) point; every sweep value away from that
   point is already extrapolation in at least one dimension. No experiment in
   this validation trains and tests at matched operating points, so the
   "in-distribution" framing in §6 is about the *generative process*, not
   about flux/dropout coverage.
4. **Silent accuracy loss.** No exception, no flag, and (per §8) the
   confidence output does not reliably rise with the true error -- it
   *underestimates* the error at every measured point.
5. **Geometry mismatch.** A model trained for one `(n_sub, n_modes)` pair
   raises `ValueError` on a mismatched slope/mask vector length
   (`ZernikeSlopeEnsemble.features`), but produces an arbitrary, unflagged
   response for a different physical geometry (subaperture pitch, pupil
   diameter) that happens to produce the same array shapes.
6. **Degenerate all-zero slope input** (e.g. every subaperture dropped except
   the one the dropout floor keeps) is accepted without error and produces
   whatever the network has learned for that corner of input space, not a
   flagged failure.

Only input-validation errors raise. **Every accuracy failure mode above is
silent.**

## 10. Reproducibility

From `products/P014/`:

```bash
PYTHONPATH=src python validation/validate_dropout.py     # full benchmark, ~55 s
PYTHONPATH=src python examples/benchmark_plot.py          # reduced run + figure, ~10 s
python -m pytest tests/ -q                                # full suite, ~7-15 s
```

Seeds: training 100, flux-sweep test 9000, dropout-sweep test 9500,
`random_state=0` for the ensemble. All data regenerates from
`numpy.random.default_rng`, so results are bit-identical on the same
numpy/scikit-learn/BLAS build. Reported floats may move in the last digits
with a different BLAS or scikit-learn version; the qualitative conclusion
(baseline wins almost everywhere; the one ML win is a baseline
instability at extreme dropout) is robust to that noise.

## 11. Compute used

CPU only, 2 x86-64 cores. Training 24.1 s; full two-sweep benchmark (10
operating points x 400 test samples, plus training) 53.6 s wall clock.
Inference is dominated by the 5-member `MLPRegressor.predict` calls, well
under 1 ms per sample. No GPU, no accelerator, no network access. Comfortably
within the mission's 2-minute-per-script compute budget.

## 12. Ethical and safety limits

- Research and education only. **This model is not certified for operational
  flight use.** No DO-178C, ECSS-E-ST-40C, or equivalent process was
  followed; there is no independent verification and no qualification
  testing.
- It must not be placed in a wavefront-sensing, adaptive-optics, or pointing
  control loop as the primary reconstructor: on this benchmark it is worse
  than the classical alternative at every flux level tested, and its
  confidence output under-states its own error rather than bounding it.
- All performance figures characterize the model against an **idealized,
  synthetic** turbulence-and-slope generator (`DATASET_CARD.md`), not against
  hardware or real atmospheric data. They are, at best, an optimistic bound;
  every unmodelled effect can only degrade them further.
- No personal data, no human subjects, no dual-use content is involved. The
  underlying physics and mathematics are standard and published.

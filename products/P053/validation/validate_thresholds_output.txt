=== false-alarm rate conversion ===
ARL0 = 1000 * 3600 * f / N samples for N false alarms per 1000 h at f Hz.
       1 per 1000 h at 20 Hz  =  7.200e+07 samples
      10 per 1000 h at 20 Hz  =  7.200e+06 samples
     100 per 1000 h at 20 Hz  =  7.200e+05 samples
  ARL0 1000 samples at 20 Hz = 50.0 s = 72000 per 1000 h

NOTE  the headline curves in this repository use a target ARL0 of 1000
NOTE  samples, i.e. 72000 false alarms per 1000 h at 20 Hz. That is far
NOTE  too many for an operational monitor. It is used because resolving
NOTE  an ARL0 of 7.2e6 samples (10 per 1000 h) by simulation needs about
NOTE  7e9 in-control samples for 1000 alarms, which does not fit the
NOTE  3-minute compute budget. The curve's SHAPE is the deliverable; the
NOTE  operating point a real requirement implies is off its right-hand end
NOTE  and is not measured here. This is stated in the README limitations.

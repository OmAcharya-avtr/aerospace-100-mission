# Requirements — twininvalidate 0.1.0

Validation level 3 obligation: numbered requirements, each mapped to the test
or validation script that exercises it. A requirement with no evidence behind
it is marked as such rather than left to look satisfied.

Status vocabulary: **MET** (evidence exists and passes), **FAILED** (evidence
exists and does not pass), **NOT MET** (deliberately out of scope, stated).

Run the mapped tests with `python -m pytest tests/ -q` and the mapped
validation scripts as listed in `validation/VALIDATION.md`.

| # | Requirement | Evidence | Status |
|---|---|---|---|

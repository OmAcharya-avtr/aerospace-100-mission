  16QAM: four bits per modulation symbol, so without a bit interleaver
  the bit errors inside one code symbol are correlated, more code symbols
  are hit than the i.i.d. model expects, and the model is therefore
  OPTIMISTIC -- the measured error rate is HIGHER than the formula. With a
  bit interleaver, which is what the model assumes, the agreement returns.

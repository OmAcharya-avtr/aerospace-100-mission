# Dataset Card — centroidnet synthetic spot frames 0.1.0

> ## The data is 100 % synthetic.
>
> **Every image used to train, validate and test this product is generated by
> `src/centroidnet/generator.py` from an idealized mathematical sensor model. No
> real detector data, no laboratory measurement and no flight data was used at
> any stage.** Reported accuracy therefore characterizes the estimators *against
> this model*, not against a physical camera. Performance on real hardware is
> unknown and unmeasured.

**Producer:** `centroidnet.generator.generate_spots` / `spot_image`
**Committed to the repository:** no — the generator is committed, the data is not.
**Regeneration:** deterministic and bit-for-bit reproducible from a fixed
`seed` via `numpy.random.default_rng`.
**License:** Apache-2.0 (same as the code that produces it).

---

## 1. What a sample is

| Field | Type | Units | Description |
|---|---|---|---|
| image | `float64` array (N, N), default N = 16 | photoelectrons (e⁻) | One simulated detector frame. May contain **negative** values (additive read noise is not clipped). |
| truth | `float64` array (2,) | pixels | Exact (x, y) spot centre relative to the array geometric centre `(N−1)/2`; +x = increasing column, +y = increasing row. |

The label is *exact by construction* — it is the parameter the image was drawn
from, so there is no labelling noise, no annotator disagreement and no label
uncertainty. This is a convenience of simulation that real data never provides.

## 2. Generative model

**Spot.** A single 2-D circular Gaussian, the standard approximation of a
diffraction-limited point-spread function near its core (Hardy 1998, *Adaptive
Optics for Astronomical Telescopes*, Oxford Univ. Press, ch. 5):

```
I(x, y) = S / (2πσ²) · exp( −((x−x₀)² + (y−y₀)²) / (2σ²) )
```

**Pixelation** (`pixelated=True`, the default and the mode used everywhere in
this product). Each pixel receives the exact integral of the Gaussian over its
unit square, which is separable and closed-form in the error function:

```
P(i, j) = S · [F(x_c+½) − F(x_c−½)] · [F(y_c+½) − F(y_c−½)]
F(u)    = ½ (1 + erf((u − x₀)/(σ√2)))
```

`pixelated=False` instead point-samples at pixel centres, an approximation valid
only for σ ≫ 1 px. It exists for comparison and is not used for training.

**Noise chain**, applied in this order:

1. add uniform background `B` [e⁻/px];
2. Poisson shot noise on (spot + background) — the correct photon/photoelectron
   statistics for a linear detector;
3. additive zero-mean Gaussian read noise, standard deviation `R` [e⁻ RMS].

**Detection SNR** reported alongside the data is
`SNR = S / sqrt(S + N_pix·(B + R²))` over the full window — the standard CCD
aperture-photometry expression (Howell 2006, *Handbook of CCD Astronomy*, 2nd
ed., Cambridge Univ. Press). It assumes the whole spot lies inside the window
and no dark current.

| Purpose | Frames | Seeds | Parameters |

| Validation training | 6 × 700 = 4200 | 100–105 | N=16, σ=1.5 px, S ∈ {100, 200, 500, 1000, 3000, 10000} e⁻, B=2.0 e⁻/px, R=3.0 e⁻, offsets U(±2 px) |

Train and test never share a seed, so the streams are independent. All splits are
drawn from the *same* distribution: this supports in-distribution generalization
claims only.

## 4. Physical effects NOT modelled

The sensor model is deliberately idealized. The following are **absent from the
data**, so no result in this product says anything about them:

- **Dead, hot and blemished pixels** — every pixel is assumed live and well-behaved.
- **Pixel-response nonuniformity (PRNU)** and **dark-signal nonuniformity
  (DSNU)** — pixel gain and offset are perfectly uniform; there is no flat-field
  structure, and no dark current at all.
- **Optical aberrations** — the PSF is an exact circular Gaussian. No coma,
  astigmatism, spherical aberration, field-dependent PSF variation, elongation,
  Airy rings or diffraction-spike structure.
- **Stray light** — the background is a spatially uniform constant. There are no
  gradients, no ghost reflections, no scattered light from a bright off-axis
  source, no earthshine or sunlit-limb intrusion.
- **Detector nonlinearity** — the response is exactly linear in photoelectrons.
  There is no full-well saturation, no clipping, no charge bleeding/blooming, no
  charge-transfer inefficiency, and no ADC quantization (data is float, not
  digitized to ADU).

Also absent, for completeness: cosmic-ray hits, multiple or extended sources in
the window, image smear from spacecraft jitter during integration, temporal
drift, thermal focus variation (σ is fixed), shutter/rolling-shutter effects,
pointing-induced motion blur, radiation-induced dark-current growth, and
inter-pixel capacitance/crosstalk.

## 5. Distribution and coverage limits

- **Offsets** are uniform in ±2.0 px about the array centre. The estimators and
  the trained model are characterized **only** in that range. Larger offsets are
  extrapolation: the quad-cell saturates at ±1.88 px by construction and the ML
  model has no training support there.
- **Spot width is fixed at σ = 1.5 px.** No defocus, wavelength or optical-design
  variation is represented. A model trained here is invalid for a different σ
  without retraining.
- **Six discrete signal levels**, not a continuum. Behaviour between and beyond
  them is interpolation/extrapolation.
- **Background and read noise are fixed** at B = 2.0 e⁻/px and R = 3.0 e⁻ RMS.
- **Window is fixed at 16×16 px.** `MLCentroider` rejects any other shape after
  fitting.
- Uniform (not Gaussian) offset sampling means the ML model's regression-to-the-
  mean shrinkage is measured against a uniform prior; a different offset prior
  would change the measured bias.

## 6. Intended use and misuse

**Intended:** benchmarking centroid estimators against each other under
controlled, exactly-labelled conditions; teaching; regression-testing this
package; sizing an error budget as an *optimistic bound*.

**Not intended:** as a substitute for detector characterization data; as evidence
of on-orbit or laboratory performance; for qualifying an estimator for flight; or
for training a model to be deployed on real hardware without retraining and
independent validation on that hardware. Because every unmodelled effect in §4
can only *degrade* real performance, numbers derived from this data should be
treated as a best case that hardware will not exceed.

## 7. Reproduction

From `products/P008/`:

```python
from centroidnet import generate_spots
images, truths = generate_spots(
    n_spots=700, grid_size=16, sigma=1.5, signal=1000.0,
    background=2.0, read_noise=3.0, offset_range=2.0, seed=100,
)
```

Identical seed and parameters reproduce identical arrays bitwise (verified by
`tests/test_generator.py::TestGenerateSpots::test_reproducibility_fixed_seed`).

## 8. Maintenance

Versioned with the package (0.1.0). Any change to the generator's noise chain or
defaults is a breaking change for reported metrics and must be recorded in
`CHANGELOG.md`, with `validation/run_validation.py` re-run and
`validation/VALIDATION.md` regenerated from the new output.

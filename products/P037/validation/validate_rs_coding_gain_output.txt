Check 3: coding gain at 10^-5, both metrics
------------------------------------------------------------------------------

  FER = 1e-5: uncoded needs 12.5230 dB, RS needs  6.7023 dB, gain = 5.8207 dB

  rate) against Eq. (1); FER metric compares Eq. (8) against Eq. (11)
  with n = 8936 bits. The two differ because a 8936-bit frame needs a
  much lower bit error rate to reach 1e-5 at the frame level.

Check 4: against the asymptotic-coding-gain bound (a formula, not a
         remembered figure)
------------------------------------------------------------------------------
G_inf = 10 log10(R (E+1)) = 10 log10(0.874510 x 17) = 11.7221 dB
  [Lin & Costello 2004 Ch. 1/12 coding-gain discussion; Sklar 2001 Ch. 8]
  BER: measured gain 3.2941 dB, 0 < gain < 11.7221 dB -> PASS
  FER: measured gain 5.8207 dB, 0 < gain < 11.7221 dB -> PASS
  Real gain well below the asymptote is the expected behaviour of a
  high-rate hard-decision block code at a moderate error rate.

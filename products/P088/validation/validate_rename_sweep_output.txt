false matches per unrelated-item opportunity -- the size confound, named
==============================================================================
The false-match rate above has a confound that has to be stated: the number of
injected renames grows with dictionary size (size // 10) while the unrelated
removals and additions stay at 2 each, so the DENOMINATOR of the rate is
dominated by true renames at the larger sizes. The rate therefore falls with
size partly by construction. The table below removes the confound by counting
false matches against the opportunity instead: 2 unrelated removals and 2
unrelated additions per seed, so 24 opportunities per cell.

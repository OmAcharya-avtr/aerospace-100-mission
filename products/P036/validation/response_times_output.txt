Recurrence (Joseph & Pandya 1986; iterative form Audsley et al. 1993):
    R_i = C_i + B_i + sum_{j in hp(i)} ceil(R_i / T_j) * C_j

2.1  Standard three-task set, no blocking.
     t1: T=7  C=3   t2: T=12 C=3   t3: T=20 C=5     (D = T for all)
     U = 3/7 + 3/12 + 5/20 = 0.428571428571 + 0.25 + 0.25 = 0.928571428571

     Hand computation:
       t1 (highest, no interference):  R = C = 3            3 <= 7   met

           R1 = 3 + ceil(3/7)*3  = 3 + 1*3 = 6

2.3  Priority-ceiling blocking turns a met deadline into a missed one.
     t1: T=7 C=3  t2: T=12 C=3  t3: T=20 C=5  t4: T=50 C=5
     Semaphore s1 used by t3 (0.001 s) and t4 (1.0 s).
     RM priorities: t1=3 > t2=2 > t3=1 > t4=0, so ceiling(s1) = 1.

     Blocking by hand (Sha, Rajkumar & Lehoczky 1990, blocked at most once):
       B_1: no lower-priority user of a semaphore with ceiling >= 3 -> 0
       B_2: ceiling(s1) = 1 < 2                                    -> 0
       B_3: t4 is lower priority and ceiling(s1) = 1 >= 1          -> 1.0 s
       B_4: nothing below it                                       -> 0

     Then for t3, R = 5 + 1 + ceil(R/7)*3 + ceil(R/12)*3:
       R0 = 6
       R1 = 6 + ceil(6/7)*3  + ceil(6/12)*3  = 6 + 3 + 3 = 12
       R2 = 6 + ceil(12/7)*3 + ceil(12/12)*3 = 6 + 6 + 3 = 15
       R3 = 6 + ceil(15/7)*3 + ceil(15/12)*3 = 6 + 9 + 6 = 21
       21 > D = 20: the 1 s blocking term costs the deadline by 1 s.
       Iteration stops at the first iterate past the deadline.

     t4 also misses, because U = 0.928571 + 0.1 = 1.028571 > 1.
     R_4 = 5 + ceil(R/7)*3 + ceil(R/12)*3 + ceil(R/20)*5:
       R0 = 5
       R1 = 5 + ceil(5/7)*3  + ceil(5/12)*3  + ceil(5/20)*5  = 5+3+3+5     = 16
       R2 = 5 + ceil(16/7)*3 + ceil(16/12)*3 + ceil(16/20)*5 = 5+9+6+5     = 25
       R3 = 5 + ceil(25/7)*3 + ceil(25/12)*3 + ceil(25/20)*5 = 5+12+9+10   = 36
       R4 = 5 + ceil(36/7)*3 + ceil(36/12)*3 + ceil(36/20)*5 = 5+18+9+10   = 42
       R5 = 5 + ceil(42/7)*3 + ceil(42/12)*3 + ceil(42/20)*5 = 5+18+12+15  = 50
       R6 = 5 + ceil(50/7)*3 + ceil(50/12)*3 + ceil(50/20)*5 = 5+24+15+15  = 59
       59 > D = 50, so iteration stops there and reports R_4 = 59.
       (Past its own period the recurrence is no longer the exact worst
        case -- see the known-limitation note in rtclock.schedulability --
        but the deadline-miss verdict is sound either way.)

# Dataset Card — ScintiNet scintillation campaign v0.1.0

## Summary

`validation/dataset.csv` — 54 rows of scintillation index σ_I² measured from
split-step phase-screen simulation across a small grid of free-space optical
link parameters in the weak-fluctuation regime. Purpose: training and
evaluation data for the `Surrogate` model and evidence for simulator
validation against Rytov theory.

The file is 5.3 kB and is committed. It is fully regenerable:

```bash
python validation/run_campaign.py    # 22.6 s wall time on 2 CPU cores
```

## Provenance

Entirely synthetic. No experimental, proprietary, personal or field-measured
data is involved. Generated by `validation/run_campaign.py` using the
simulator in `src/scintinet/simulator.py` (angular-spectrum propagation
between FFT-synthesised Kolmogorov phase screens; Schmidt 2010, Goodman 2005,
Andrews & Phillips 2005).

## THE CAMPAIGN IS REDUCED-SCALE

**This dataset was deliberately shrunk to fit a 2-CPU-core, sub-3-minute
compute budget. It is not a converged simulation campaign and must not be
treated as one.** What was reduced, and what a full campaign would require:

| Aspect | This campaign | A production campaign |
|---|---|---|
| Grid | 256² | 1024²–4096² (resolves inner scale and wider spatial dynamic range) |
| Domain | 0.5 m | 2–4 m (more speckle cells per frame, lower statistical error) |
| Phase screens | 8 | 20–50 (converged split-step discretisation; convergence study required) |
| Realizations per point | 8 | 500–5000 (σ_I² statistical error ∝ 1/√N; ~1 % rather than ~10 %) |
| Parameter points | 18 (Cn², L, λ) × 3 apertures = 54 rows | 10³–10⁴ points including Cn²(h) profiles, slant paths, beam types |
| Subharmonics | not implemented | Lane et al. (1992) subharmonic augmentation, 3+ levels |
| Wall time | 22.6 s | 10³–10⁵ core-hours |
| Regime | weak only (σ_R² ≤ 0.30) | weak + moderate + strong, with saturation |

Consequences for the data: per-point σ_I² carries an estimated ~5–10 %
statistical error from the 8-realization average, and a systematic low bias
from the missing sub-fundamental screen frequencies (measured: ~2 % for a
point receiver, ~15 % averaged over 50–100 mm apertures — see
`validation/VALIDATION.md` §V3).

## Schema

| Column | Units | Description |
|---|---|---|
| `cn2` | m^(−2/3) | Refractive-index structure parameter (constant along path) |
| `path_length_m` | m | Propagation path length L |
| `wavelength_m` | m | Optical wavelength λ |
| `aperture_d_m` | m | Receiver aperture diameter D (0.002 m ≈ 1 pixel ⇒ point-like) |
| `sigma_i2_sim` | – | **Target.** Aperture-averaged scintillation index from simulation |
| `sigma_i2_sim_point` | – | Point (single-pixel) scintillation index for the same run |
| `sigma_i2_rytov` | – | Analytic baseline: aperture-averaged weak-fluctuation Rytov index |
| `seed` | – | RNG seed for that simulation point |

## Coverage

| Parameter | Values |
|---|---|
| Cn² [m^(−2/3)] | 1e-16, 3.16e-16, 1e-15 (weak to moderate ground-level turbulence) |
| L [m] | 1000, 2000, 3000 (horizontal terrestrial links) |
| λ [m] | 8.5e-7, 1.55e-6 (common FSO bands) |
| D [m] | 0.002, 0.05, 0.1 |
| Resulting σ_R² | 4.0e-3 to 3.0e-1 — **entirely within the weak-fluctuation regime** |
| Resulting σ_I² (target) | 1.1e-4 to 2.7e-1 |

Each (Cn², L, λ) point is one simulation run; the three aperture rows from a
run share a seed and are therefore **statistically correlated**. The
benchmark's random row split does not account for this, so held-out aperture
rows are slightly optimistic — a group split by simulation point would be
stricter. Documented rather than corrected.

## Determinism

Simulation point *i* (iterating Cn² outer, then L, then λ) uses seed
`2026 + i`. Same code, same seeds, same NumPy version ⇒ bit-identical CSV.

## Known limitations and gaps

- Plane-wave source only. No Gaussian-beam or spherical-wave data, so a
  surrogate trained on this cannot represent beam-divergence effects.
- Horizontal, homogeneous Cn² only. No Cn²(h) altitude profiles
  (e.g. Hufnagel-Valley), so no satellite or slant-path coverage.
- Kolmogorov spectrum with no inner or outer scale.
- No subharmonic augmentation ⇒ deficient low-spatial-frequency power.
- Weak regime only. σ_R² never exceeds 0.30; nothing about the focusing peak
  or the saturation regime is represented.
- No temporal dimension: no wind, no frozen-flow time series, no fade
  duration or fade-rate statistics.
- 8 realizations per point ⇒ non-negligible statistical noise in the target.
- Only 54 rows. Far too small for a model expected to generalise; the
  surrogate benchmark result reflects this directly.

## Intended and unintended use

**Intended:** research and teaching; demonstrating the surrogate workflow;
regression-guarding the simulator.

**Not intended:** training any model used for operational FSO link budgets,
availability prediction, or mission-critical planning. This dataset is not
certified for operational flight use.

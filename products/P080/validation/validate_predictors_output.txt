portability: which predictors are bit-exact on any machine
==============================================================================
predictor       arithmetic           cross-machine bit-exact  
--------------  -------------------  -------------------------
previous        integer only         yes                      
linear          integer only         yes                      
quadratic       integer only         yes                      
cubic           integer only         yes                      
learned_linear  float64 dot product  no (libm-free, but float)
learned_mlp     float64 with tanh    no (tanh is a libm call) 

A coder whose decoder runs on different silicon from its encoder needs the
prediction to be reproducible bit-for-bit, because the residual stream is
decoded against it. The classical predictors give that for free. The learned
ones do not, and no amount of rate improvement substitutes for it.

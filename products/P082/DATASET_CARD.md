# Dataset card: the synthetic concurrent cloud record

## In one sentence

Everything in this repository is measured on a **synthetic** concurrent
cloud-cover record generated by `sitediverse.field` from declared constants and
a fixed integer seed. **No real site climatology is used. No real optical ground
station is a data source. Not one number in this repository is a measurement of
the atmosphere.**

## What a reader must not conclude from it

The generator has a **known** spatial correlation structure, and that is the
only reason this product can score its estimators against a truth. It is also
exactly why nothing measured here transfers to a real network:

- The record's correlation is **exponential in an elliptical effective
  separation** by construction, equation (4). On the `isotropic` control record
  the two-parameter model of `sitediverse.correlation` is therefore
  **correctly specified by construction**, and the small error it achieves
  there is a property of the generator, not evidence that an exponential is the
  right model for real cloud correlation.
- The marginal climatology is **two harmonics in probit space**, equation (6).
  Real cloud climatology is not, and the cell estimator of `climatology` is
  flattered by that.
- The temporal structure is a **first-order autoregression**, equation (5). Real
  cloud fields have longer memory and regime-switching behaviour the AR(1) does
  not reproduce.
- A model that recovers the parameters of its own generator has demonstrated
  **consistency**, not skill. Every ground-truth score in `validation/` is a
  consistency check and is labelled as one.

A reader who wants the figures in this repository to mean something about their
own network must supply their own concurrent record. The geometry functions in
`sitediverse.geometry` take arbitrary coordinates and every estimator in the
package takes a `(epochs, stations)` boolean array; nothing in the pipeline
knows the record is synthetic except `sitediverse.field`, and
`tests/test_properties.py` checks that structurally by rerunning the whole study
on a record whose ground-truth arrays have been zeroed.

Twenty declared synthetic stations in five groups of four, built by
`geometry._declared_network` from `CLUSTER_CENTRES` and `CLUSTER_OFFSETS`.

**These are declared synthetic coordinates. They are not the coordinates of any
real optical ground station**, and no station's climatology, cloud statistics or
availability record is used anywhere in this package. Altitudes are carried on

Three, all from the same generator. `anisotropic` is the reference, `isotropic`
is the control, and `short` is what the test suite uses wherever the claim under
test does not depend on record length.

The isotropic control replaces each regime's two lengths by their **geometric
mean**, so the correlation ellipse keeps its area and the field becomes
isotropic. It uses a different seed so that the two records are not the same
noise wearing different structure.

## The generator, in four equations

Written out in full in the module docstring of `src/sitediverse/field.py`.

1. **Equation (4), space.** `R_ij(r) = rho_0 exp(-sqrt((d_along/L_along(r))^2 +
   (d_cross/L_cross(r))^2))`. Exponential, which is the Matern covariance at
   smoothness one half (Stein 1999, chapter 2). `rho_0 < 1` is a nugget: the
   part of a station's variability that is local to it, which in a cloud field
   is the sub-grid convective cell.
2. **Equation (5), time.** `z_t = phi z_{t-1} + sqrt(1 - phi^2) e_t` with
   `e_t ~ N(0, R)`. Separable in space and time by construction.
3. **Equation (6), the indicator.** `c_it = 1` if `z_it < Phi^{-1}(q_it)`, with
   `q_it` a seasonal and diurnal modulation applied in **probit** space so that
   `q_it` stays strictly inside `(0, 1)`. The marginal cloud probability is
   therefore exactly `q_it` and is known.
4. **Four seasonal regimes.** The year is divided into four equal quarters and
   each carries its own `(L_along, L_cross)`. This is the single feature of the
   record that an isotropic two-parameter model fitted on great-circle
   separation cannot represent.

Thresholding destroys correlation: the binary indicator is substantially less
persistent than the latent field, and that gap is why `climatology` uses the
**indicator's** lag-one in equation (13) and says so.

## The thing a thresholded Gaussian cannot promise

`c_it` is a **strict comparison of two rounded quantities**. Two builds that
agree on the latent field and the threshold to within one unit in the last place
can disagree on the indicator wherever the two sit within an ulp of each other.
Measured in `validation/validate_field_output.txt`:

| perturbation of the latent field | indicators flipped, of 467200 | cloud-rate change |
| --- | --- | --- |
| 1e-16 | 0 | 0 |
| 1e-12 | 0 | 0 |
| 1e-08 | 0 | 0 |
| 1e-04 | 15 | 3.210616e-05 |

Every flipped indicator had a margin `|z - threshold|` inside the perturbation
that flipped it. **No test or check in this repository asserts bit-exact
equality of a cloud indicator.** Tests assert that the cloud *rate* agrees to a
tolerance and allow an individual indicator to differ only where the margin is
inside that tolerance.

## Intended use and misuse

**Intended.** Measuring the error of the independence assumption against a
record whose correlation structure is known; comparing correlation models on a
problem where the truth exists; testing an implementation of a Gaussian-copula
site-diversity calculation.

**Not intended.** Any statement about the availability of any real optical
ground station or network. Any statement about the correlation length of any
real cloud field. Any input to a link budget, a mission availability analysis or
an operational decision.

## Ethical and safety limits

The record describes no person and contains no personal data. The product it
feeds is research grade: **not flight-qualified, not certified, not approved for
operational aerospace use.** A reader who takes an availability figure from this
repository into a real link budget has made an error this card exists to
prevent.

## Reproduction

```bash
python -m sitediverse record --record anisotropic
python validation/validate_field.py
python examples/record_structure.py
```

Every one is deterministic in the declared seed and requires no network
connection and no data download.

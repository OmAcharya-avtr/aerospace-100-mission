pytest.approx(expected, rel=r) passes if EITHER bound is met and the
absolute default is 1e-12, so a bare rel= on a small quantity stops testing
what it says. This script measures the dependence rather than asserting its
absence. It matters more here than in most products: this one's quantities
include joint unavailabilities of order 1e-03, a correlation excess driven
down to 1e-25, and an exact decomposition whose residual is 1e-16.

4. why the list in part 3 is the same on every run
==============================================================================
A predecessor in this mission shipped an audit whose list of named failing
tests changed from run to run, because Hypothesis generated different
examples each time and the membership depended on them. That makes the
report worthless as evidence.

  Hypothesis is DERANDOMISED here and its example database is disabled. Two
  and the database is disabled so that a stale local database cannot make a

  max_examples=30,
  deadline=None,
  derandomize=True,
  database=None,
  settings.load_profile("sitediverse")

[PASS] the Hypothesis profile is derandomised and its database is disabled -- both settings found in tests/conftest.py

example database cannot influence the runs above even if one existed.

# FogCast Model Card

**This model is not certified for operational flight use.**

## Problem

Predict fog/aerosol specific optical attenuation (dB/km) for free-space optical (FSO)
links from meteorological visibility V (km), wavelength lambda (nm), and relative
humidity RH (%), with a calibrated uncertainty output (90 % prediction interval).

## Baseline (implemented first, benchmarked against)

Kim empirical model (Kim, McArthur, Korevaar, Proc. SPIE 4214, 2001) and Kruse model
(Kruse et al. 1962, "Elements of Infrared Technology"), both of the Koschmieder form
`alpha = (10/ln 10)(3.912/V)(lambda/550)^(-q(V))` dB/km with their respective piecewise
q(V). Exposed as `kim_attenuation_db_km()` and `kruse_attenuation_db_km()`.

## Architecture

Three scikit-learn `GradientBoostingRegressor` instances on features
`[log10(V_km), lambda_um, RH_percent]`, target `log10(alpha_dB/km)`:
squared-error loss for the point estimate, quantile loss at alpha = 0.05 and 0.95 for
the interval bounds (monotone back-transform `10**y` preserves quantiles).
Hyperparameters: 300 estimators, max depth 3, learning rate 0.05, `random_state=42`.
Quantile crossing is guarded by clipping so lower <= point <= upper always holds.

## Dataset source and limitations

Seeded synthetic dataset (n = 6000) generated by the committed script
`src/fogcast/dataset.py` — see `DATASET_CARD.md`. **Critical limitation: the ground
truth is the Kim model plus synthetic perturbations, not field measurements. All
metrics below are relative to that synthetic generative process, not to the real
atmosphere.**

## Training procedure and test-split strategy

Deterministic 70/15/15 train/validation/test split (`split_indices`, permutation seed
= dataset seed + 1): 4200/900/900. The model is fit on the training split only; the
validation split is reserved for hyperparameter sanity checks; all reported metrics
use the untouched 900-sample test split.

## Metrics (held-out test split, actual run — see validation/benchmark_results.md)

| Predictor | MAE (dB/km) | RMSE (dB/km) |
|---|---|---|
| ML (this model) | 2.320 | 5.390 |
| Kim baseline | 2.465 | 5.749 |
| Kruse baseline | 7.675 | 15.043 |

## Uncertainty / confidence output

`predict(..., return_interval=True)` returns `(point, lower, upper)` — a nominal 90 %
prediction interval from the two quantile models. Empirical coverage on the held-out
test split: **0.879** (nominal 0.90; acceptance band 0.85–0.95, enforced by a unit
test). Median interval width 2.60 dB/km.

## Failure cases

- **Real fog**: trained only on synthetic Kim-derived data; systematic error of the Kim
  model against real fog is invisible to this model and NOT captured by its intervals.
- **Extrapolation**: V in (50, 100] km and lambda in [500, 600) or (1700, 2000] nm are
  accepted (baseline validity range) but lie outside the training distribution;
  intervals there are unreliable. Piecewise-constant tree output also produces visible
  step artifacts (see the example figure).
- **Dense fog (V < 0.5 km)**: the published baselines themselves disagree (Kim vs Kruse
  ratio 1.5 at V = 0.3 km, 1550 nm); structural uncertainty exceeds the statistical
  interval.
- **Slight edge only**: on this synthetic truth the model beats the Kim baseline by
  ~6 % MAE overall and is marginally *worse* than Kim in the 0.5–1 km fog band; the
  Kim baseline should be preferred wherever its assumptions hold.
- Not applicable to rain, snow, molecular absorption lines, or turbulence/scintillation.

## Reproducibility

```
cd products/P009
PYTHONPATH=src python -c "from fogcast import FogCastModel; FogCastModel.train_default(n_samples=6000, seed=42)"
PYTHONPATH=src python validation/benchmark_ml.py   # regenerates the metrics table
python -m pytest tests/ -q                          # includes same-seed => same-predictions test
```

All randomness flows from a single seed (default 42): dataset draws, split permutation
(seed + 1), and the three regressors' `random_state`. Same seed => bit-identical
predictions (unit-tested).

## Compute used

Training: ~5 s on 2 CPU cores (3 GBR fits, 4200 samples). Full test suite: ~10 s.
Well within the 3-minute budget.

## Ethical / safety limits

Research-grade tool for link-budget studies and ML-uncertainty education. It must not
be used to make operational availability, safety, or flight decisions. Outputs are only
as good as the Kim empirical model plus synthetic assumptions behind the training data.
**This model is not certified for operational flight use.**

usage: python -m activityplan [-h] [--version]
                              {instances,declare,plan,compare,predict,robust,warmstart} ...

Onboard activity planning with an auditable feasibility report: a timeline, the binding constraint, and the slack on every other constraint.

positional arguments:
  {instances,declare,plan,compare,predict,robust,warmstart}
    instances           list the shipped hand-declared instances
    declare             print one instance's declaration and its
                        discretisation
    plan                plan one instance and print the timeline and
                        feasibility report
    compare             greedy against the exact optimum
    predict             learned duration and energy predictor against the
                        analytic model
    robust              the four planning modes under realised durations
    warmstart           does a learned warm start help the exact solver

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit

activityplan is research-grade software. It is not flight-qualified, not
certified, and not approved for operational aerospace use. Every constant in
every shipped instance is a declared input of a synthetic benchmark and none was
identified from any spacecraft.

A plan this tool calls feasible is feasible with respect to the declaration you
supplied, on the discretised timeline you chose, under a resource model whose
assumptions are listed in the module docstrings. Change the step and you change
the answer.

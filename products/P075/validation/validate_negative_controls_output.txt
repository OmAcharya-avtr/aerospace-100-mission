  Offsetting a value by its tolerance does NOT guarantee a violation:
  the reference may already sit up to one tolerance away on the other
  side, so only an offset strictly greater than TWICE the tolerance
  guarantees failure. Every control here uses a factor of
  10, anchors on the true value or on the bracket's own width, and
  reports whether it fired as its own check.

  A control that does not fire is a failure of the VALIDATION, not of
  the product, and it is the one kind of failure that would otherwise
  be invisible.

control 1: a closed-form agreement check, broken on purpose
==============================================================================

  The real check: the k-of-n reliability agrees with the binomial
  survival to 1e-13 relative. The control perturbs the computed value by
  10 times that tolerance, which is strictly more than twice it, so
  the check MUST fail.

  true computed reliability          : 0.722696003225790
  independent reference              : 0.722696003225790
  real relative error                : 1.536224e-16
  declared tolerance                 : 1.0e-13
  injected offset                    : 10 x tolerance, relative
  perturbed value                    : 0.722696003226513
  perturbed relative error           : 1.000236e-12

  [PASS] the real check passes -- 1.536224e-16
  [PASS] the injected offset DOES break the check, so the control fires -- perturbed error 1.000236e-12 exceeds tolerance 1.0e-13

  for contrast, an offset of exactly 1 x the tolerance:
    perturbed relative error         : 1.000082e-13
    would the check fail             : True

  That is the point of the 2x rule: a 1x offset is on the boundary and
  its verdict depends on which side the real error already sat.

control 3: a wrong cut set, broken on purpose
==============================================================================

  The real check: every reported minimal cut set fails the system when
  all its events fail, and restoring any one of them restores the
  system. The control feeds a deliberately wrong cut set -- a proper
  SUBSET of a real one -- to the same test and requires it to be
  rejected. A subset is the right injection here because a superset
  would still fail the system and would pass the first half of the
  check.

  real minimal cut set               : {a, b}
  system fails when it is down       : True
  injected subset                    : {a}
  system fails when only it is down  : False
  real cut set is minimal            : True
  injected superset                  : {a, b, single}
  superset passes the minimality test: False

  [PASS] the real cut set fails the system
  [PASS] the real cut set is minimal
  [PASS] the injected subset DOES NOT fail the system, so the control fires -- a proper subset of a minimal cut set cannot be a cut set
  [PASS] the injected superset DOES fail the minimality test, so the control fires -- a superset of a minimal cut set is not minimal

control 5: a Monte Carlo interval, broken on purpose
==============================================================================

  The real check is the 4-standard-error criterion this repository
  declares everywhere else, not membership of the 95 percent interval:
  a 95 percent interval is expected to miss about 1 run in 20 BY
  CONSTRUCTION, so making it the pass criterion of a single seeded run
  would be a check that fails 5 percent of the time for no reason.
  Interval membership is reported alongside, as information.

  The control offsets the closed form by the FULL interval width times
  10, which is more than twice the half-width, so it must fall
  outside.

  closed form R                      : 0.844054788280
  simulated R                        : 0.842897500000
  interval                           : [0.841766498624, 0.844021915306]
  interval half-width                : 1.127708e-03
  injected offset                    : 2.255417e-02
  perturbed closed form              : 0.866608955092

  distance in standard errors        : 2.0114
  inside the 95 percent interval     : False

  [PASS] the real check passes the declared 4-standard-error criterion -- 2.0114 standard errors
  [PASS] the injected offset DOES fall outside the interval, so the control fires -- 41.2106 standard errors from the estimate

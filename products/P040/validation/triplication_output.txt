Cost of triplication
==============================================================================
scheme                    selective_triplication
protected                 588 bytes
extra memory              1176 bytes
memory factor             3.000x
latency overhead          0.003000 of inference time
(the inference and vote times above are the illustrative 1 ms / 3 us pair;
the measured figures for this host are in examples/mitigation_tradeoff.py)

What triplication does NOT buy, stated plainly:
  - it does not reduce the upset rate, only the probability that an upset
    changes the result;
  - 3x memory on the protected region means 3x the exposed bits in that
    region, so the rate of double upsets within a voted triple grows with
    the protection, which is why the scrub interval matters;
  - a word voter that flags an uncorrectable element has still lost that
    element; detection is not correction.

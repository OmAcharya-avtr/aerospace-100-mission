# Dataset card — downlinkpick synthetic generator 0.1.0

Every dataset used by this package is synthetic and is produced by
`src/downlinkpick/dataset.py` from fixed seeds. **No real spacecraft recorder
inventory, no real contact plan, no real link budget and no real codec output is
used anywhere in this repository.** Nothing was fitted to flight data because
this build had none.

That is the dominant limitation on every learned result in `MODEL_CARD.md` and
on several in `validation/VALIDATION.md`, and it is stated first rather than
last.

## What is committed and what is generated

| Artifact | Committed? | Size | Regenerated by |
|---|---|---|---|
| `examples/cases/three_pass_declared.yaml` | yes | 10 965 bytes | `validation/regenerate_cases.py` |
| `examples/cases/missing_declarations.yaml` | yes | 10 872 bytes | `validation/regenerate_cases.py` |
| `examples/cases/single_short_pass.yaml` | yes | 4670 bytes | `validation/regenerate_cases.py` |
| Training tables (6000 rows each) | no | regenerated in seconds | `generate_training_table(6000, seed)` |
| Benchmark instance families | no | regenerated in seconds | `generate_instance(seed, ...)` |

Nothing above 1 MB is committed. `validation/regenerate_cases.py` regenerates
the three committed cases from their seeds and exits non-zero if the result is
not byte-identical, so a change to the generator that would silently change a
shipped case fails a check instead of passing quietly.

## Generating equations

These are the equations in the module docstring of `downlinkpick.dataset`,
reproduced so that this card stands alone. For a product with instrument `k`,
novelty `nu` in [0, 1], coverage `chi` in [0, 1], age `a` seconds and latent site
weight `omega`:

```
realised value      V = A_k * nu**0.7 * chi * exp(-a / tau_k) * omega        (3)
fresh declaration   D_fresh = V * (1 + eta),        eta ~ N(0, sigma_d)      (4)
stale declaration   D_stale = A_k * nu**0.7 * chi * omega * (1 + eta)        (5)
```

Equation (5) is equation (3) evaluated at `a = 0`: a declaration written when
the product was recorded and never revisited. **`omega` is latent** — it is not
a feature of any model in this package — so it is the irreducible error floor of
every value estimator measured here.

For compressibility, with first-order entropy `H` bits per sample, stored bit
depth `B` and lag-one autocorrelation proxy `rho` in [0, 1]:

```
memoryless floor    f = min(H / B, 1)                                        (6)
realised ratio      r = clip(f * g_k * (1 - 0.55 * rho) * (1 + zeta), 0.02, 1) (7)
```

with `zeta ~ N(0, 0.06)` and `g_k` a per-instrument codec factor. Equation (6)
is Shannon's source-coding bound for a memoryless source; equation (7)
deliberately goes **below** it, because a real codec exploits the correlation
that the memoryless bound ignores. That is why the entropy floor is a biased
estimator in the measurements and why measuring the bias is worth doing.

## Instrument classes

Five classes, spanning three orders of magnitude in size and a factor of twelve
in value decay time. **These numbers are chosen to create genuine tension
between value, size and deadline. They are not measured from any instrument.**

| Label | `A_k` [value units] | `tau_k` [s] | `g_k` | bit depth | channels | entropy range [bit/sample] | size range [byte] |
|---|---|---|---|---|---|---|---|
| `msi` | 9.0 | 7.2e4 | 0.95 | 12 | 6 | 6.5 to 10.5 | 4.0e7 to 9.0e8 |
| `sar` | 14.0 | 2.6e5 | 1.05 | 16 | 2 | 11.0 to 15.0 | 2.0e8 to 4.0e9 |
| `hsi` | 20.0 | 1.4e5 | 0.88 | 14 | 48 | 7.0 to 12.0 | 6.0e8 to 8.0e9 |
| `hkt` | 3.0 | 8.6e5 | 0.70 | 16 | 1 | 2.0 to 6.0 | 1.0e5 to 4.0e6 |
| `cal` | 6.0 | 6.0e6 | 0.80 | 12 | 1 | 4.0 to 8.0 | 2.0e6 to 3.0e7 |

## Sampling distributions

| Quantity | Distribution |
|---|---|
| instrument | uniform over the five classes |
| `raw_bytes` | log-uniform over the class's size range |
| `entropy_bits_per_sample` | uniform over the class's entropy range, capped at the bit depth |
| `age_s` | uniform on [0, 4 x horizon] |
| `expiry_s` | uniform on [0.12, 1.6] x horizon |
| `novelty` | Beta(2, 2) |
| `coverage_fraction` | Beta(7, 1.6) |
| `lag1_autocorr` | Beta(3, 2) |
| `omega` (site weight, latent) | log-normal, `exp(N(0, 0.33))` |
| dependency | with probability `dependency_fraction`, one prerequisite drawn uniformly from the products already generated |

The default horizon is 43 200 s (12 hours). Dependencies point backwards in
generation order by construction, so the graph is acyclic without rejection
sampling.

## Contact plan

`n_windows` non-overlapping passes at evenly spaced starts within the horizon,
each with a jittered duration on [240, 600] s, a peak rate jittered by a factor
on [0.6, 1.4], a reliability drawn uniformly on [0.72, 1.0], and a symmetric
rise-and-fall rate profile sampled at 9 breakpoints.

**The rate profile is a shape, not a link budget.** It is
`peak * (floor + (1 - floor) * sin(pi u))` for `u` in [0, 1]. There is no
antenna pattern, no atmospheric model, no modcod table and no slant range in it.
A real contact plan's profile comes from a link budget and should be supplied as
measured breakpoints.

`capacity_fraction`, default 0.45, rescales the peak rate so that the plan's
total capacity is that fraction of the queue's total compressed size. This is
the knob that puts an instance in the regime the product exists for: the contact
is shorter than the queue and something has to be left behind. Capacity is
linear in the peak rate for this profile, so the rescaling is exact.

## Determinism

Every draw goes through `numpy.random.default_rng(numpy.random.SeedSequence([seed, tag]))`
with a distinct tag per stream, so the product stream, the plan stream and the
training-table stream are independent and each is reproducible from its seed
alone. `tests/test_dataset.py` asserts that the same seed and keyword arguments
reproduce an identical instance, and `validation/regenerate_cases.py` asserts it
at the byte level for the three committed cases.

Seeds used in this build:

| Seed | Purpose |
|---|---|
| 1001 | value-model training table |
| 1002 | compressibility-model training table |
| 1 to 300 | greedy-gap and invariant instance families |
| 1 to 240 | small instances for the enumeration check |
| 5001 to 5030 | value-model benchmark instances |
| 6001 to 6030 | compressibility benchmark instances |
| 20261021 | `three_pass_declared` case, and both model `random_state` values |
| 20261022 | `missing_declarations` case |
| 20261023 | `single_short_pass` case |
| 4242 | the session-scoped training table in the test suite |

The training seeds and the benchmark seeds are disjoint streams, so no product
in any benchmark appears in a training table.

## Limitations

- **It is synthetic.** Every number measured against it is a statement about
  these equations. Nothing here establishes that a real recorder inventory looks
  like this, and the most likely way the measurements mislead is that the real
  relationship between features and realised value is weaker, noisier or
  differently shaped.
- **Value decay is exponential and instrument-specific.** Real value decays in
  ways that depend on what the data is for: a weather product has a hard
  assimilation deadline and a calibration frame does not decay at all.
- **Declared values are wrong in exactly two ways** — multiplicative noise, or
  staleness through ignoring the decay since acquisition. Real declarations are
  also wrong through inconsistent units between teams, political weighting, and
  a value scale that is not additive across instruments. None of those is
  modelled, and the last of them is the assumption the whole selection rests on.
- **Compressibility comes from an equation, not a codec.** `numcodecs` is the
  package to reach for to measure a real ratio; it is named in the alternatives
  table in `README.md` and is not a dependency of this package.
- **Dependencies are single-parent and shallow by construction.** The deepest
  transitive closure observed in 400 instances at `dependency_fraction=0.65` was
  8, and a real processing graph can be wider and deeper.
- **Reliability is independent across windows.** Weather at one station is
  correlated with weather at the same station on the next orbit, and a shared
  ground segment correlates across stations. Neither is modelled.

  usage: python -m invariantset [-h] [--version]
                                {systems,invariant,tolerance-sweep,algebra} ...
  
  Maximal robust invariant sets for discrete-time linear systems with bounded
  disturbances. Research-grade; not flight-qualified, not certified, not
  approved for operational aerospace use.
  
  positional arguments:
    {systems,invariant,tolerance-sweep,algebra}
      systems             list the built-in example systems
      invariant           compute the maximal robust invariant set
      tolerance-sweep     run the recursion once per redundancy tolerance and
                          compare answers
      algebra             measure the Minkowski/Pontryagin asymmetry on a worked
                          2-D case
  
  options:
    -h, --help            show this help message and exit
    --version             show program's version number and exit

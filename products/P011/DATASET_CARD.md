# Dataset Card — WaveForge synthetic slope sequences 0.1.0

**Product:** P011 WaveForge · **Version:** 0.1.0 · **License:** AGPL-3.0-or-later

## 1. What this data is

Time series of Shack-Hartmann slope measurements produced by the simulator in
this repository. **The data is entirely synthetic.** It is generated by a
Kolmogorov phase-screen model translated across the pupil under Taylor's frozen
flow, sampled by a geometric Shack-Hartmann sensor model. It contains no
measurement of any real atmosphere and no personal data of any kind.

Accuracy measured on this data is therefore accuracy **against a generative
process**, not against the sky. Section 5 states what that process does and does
not reproduce.

## 2. Nothing is committed

No dataset file is stored in this repository. Every array is regenerated
deterministically from an integer seed:

```bash
cd products/P011
PYTHONPATH=src python -c "
from waveforge.datasets import make_slope_dataset
data = make_slope_dataset(n_frames=400, train_seeds=(101,102,103), test_seeds=(901,))
print(data.summary())
"
```

The default dataset is 1200 training frames × 104 slopes plus 400 test frames
(1.3 MB as float64 in memory), which regenerates in about 7 s. The largest
in-memory arrays in the package — the 1024² generating screen (8 MB) and the
influence-function matrix (2.6 MB) — are likewise never written to disk.

## 3. Generation

| Stage | Model | Source |
|---|---|---|
| Phase screen | Fourier method with Lane et al. subharmonics, 1024², six levels | McGlamery 1976 *Proc. SPIE* **74**, 225; Lane, Glindemann & Dainty 1992 *Waves in Random Media* **2**, 209 |
| Spectrum | Kolmogorov, `Φ(f) = 0.0229 r₀^(−5/3) f^(−11/3)` | Roddier 1981 *Prog. Optics* **19**, 281 Eq. 3.14; Hardy 1998 Eq. 3.55 |
| Time evolution | rigid translation at the wind speed | Taylor 1938 *Proc. R. Soc. A* **164**, 476 |
| Sensing | subaperture-averaged phase gradient | Hardy 1998 Sec. 5.2 |
| Noise (optional) | centre-of-gravity photon and read-noise variances | Rousset 1999, in *Adaptive Optics in Astronomy* ed. Roddier, Ch. 5 |

Default configuration: 0.5 m aperture, `r₀ = 0.10 m` at 1.55 µm (`D/r₀ = 5`),
10 m/s wind, 1 kHz frame rate, 8 × 8 lenslets giving 52 illuminated
subapertures and 104 slopes, 64 × 64 pupil samples.

## 4. Splits

| Split | Seeds | Frames |
|---|---|---:|
| Train | 101, 102, 103 | 3 × 400 |
| Held-out (open loop) | 901 | 400 |
| Held-out (closed loop) | 901, 902 | 2 × 500 |
| Gain tuning | 555 | 300 per configuration |

Train and test are **different phase-screen realisations**. A frozen-flow slope
sequence is strongly autocorrelated — that autocorrelation is precisely what
the predictor exploits — so a random or contiguous split of one sequence would
leak the test signal into training and inflate every score.
`make_slope_dataset` refuses overlapping seed sets.

Sensor-noise streams are also disjoint: 4242 for gain tuning, 8888 for training
noise, 31337 for evaluation, so no noise realisation is ever shared between
fitting and scoring.

## 5. Known limitations of the generating process

These are the reasons a result on this data may not transfer:

1. **Single layer, constant wind.** Real turbulence is multi-layer with
   different speeds and directions per layer, and it boils. Single-layer frozen
   flow is the most predictable atmosphere possible, so any predictive
   controller's advantage measured here is an **upper bound**.
2. **Low-frequency deficit.** A Fourier screen carries no power below
   `1/(N d)`. With six subharmonic levels the measured structure function
   reaches 1.00 of theory at separations ≥ 0.1 m, but the pupil-integrated tip
   and tilt variances still sit at **0.82** of the analytic Kolmogorov values
   (`validation/validate_atmosphere.py` §5d).
3. **High-frequency truncation.** No power above the grid Nyquist. For the
   default 64-pixel pupil this removes about 3 % of the fitting-error term of a
   9 × 9 mirror and about 10 % for a 33 × 33 one.
4. **Infinite outer scale.** Kolmogorov by default. A finite outer scale is
   available (`outer_scale_m`) but was not used for the benchmark data.
5. **Geometric sensor.** Slopes are exact subaperture-averaged gradients plus
   additive Gaussian noise. There is no spot image, so spot truncation,
   elongation, non-linearity and centroid bias are absent. The spot-level model
   is product P018 ShackSim.
6. **No scintillation.** Pupil amplitude is uniform.
7. **Periodicity guard.** The subharmonic component is not periodic, so a
   frozen-flow run longer than `FrozenFlowAtmosphere.max_frames` is refused
   rather than allowed to wrap and splice two uncorrelated edges together.

## 6. Intended use and misuse

Intended for benchmarking wavefront reconstruction and predictive control
inside this package, and for teaching. **Not** intended as a stand-in for
measured turbulence, for validating a link budget, or for any claim about
performance on the sky. Anyone quoting a number obtained on this data must
state that the data is simulated.

## 7. Provenance record

`SlopeDataset.summary()` returns the seeds, frame counts, slope count, noise
sigma, noise seed and the physical configuration, so a result can be traced
back to the exact generator settings that produced it.

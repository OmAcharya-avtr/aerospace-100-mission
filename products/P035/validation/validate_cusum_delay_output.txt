Detection delay the way an operator sees it
------------------------------------------------------------------------------
The rows above start the chart at the same instant as the shift.  In a
monitoring window the chart has already been running, so the delay from a
mid-window onset is shorter than ARL1: the chart is not starting from zero.
Measured over 4000 windows of length 200 with the step at sample 100:

 delta  Pd within 100   mean delay       SE  ARL1 (markov)    ratio
   0.5         0.8273      39.3841   0.4265        56.4720    0.697
   1.0         0.9475      11.3900   0.1040        13.0740    0.871
   1.5         0.9565       5.6226   0.0420         7.0984    0.792
   2.0         0.9523       3.5345   0.0245         4.9103    0.720
   3.0         0.9440       1.9266   0.0128         3.1196    0.618

The ratio is below 1 because the CUSUM arm is already above zero when the
shift starts, so the warm chart needs fewer samples than a cold one.  That
is a property of the chart, and the reason the detection-delay tables in
this package always state the onset index.

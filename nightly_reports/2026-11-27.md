### Root cause — measured, not inferred

The Keychain has **no github.com credential at all**:

- `security find-internet-password -s github.com` → `NO ENTRY FOUND`
- `security find-generic-password -s github.com` → `no generic entry`
- `printf 'protocol=https\nhost=github.com\n\n' | git credential-osxkeychain get` → **empty output**

The helper is still configured (`credential.helper=osxkeychain` globally and in the repo) but
has nothing to hand git. Git therefore attempts an empty credential, and GitHub answers with
the "Invalid username or token" line above. No token was read, displayed, copied or logged at
any point; presence was probed, never the value.

Whether the credential was deliberately revoked by the owner or silently evicted by macOS is
**not determinable from here, and that is one reason this session did not publish anything.**

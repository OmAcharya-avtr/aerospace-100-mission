The open item from 2026-10-17 is closed for P064 and P065, and the predecessor's
count does not reproduce. Measured with `bandit -r products/P064 products/P065`:
**three** B314 MEDIUM findings excluding tests, **four** including them — not the

Triaged by execution, not by reading. On CPython 3.13.16, against this
package's own `parse_junit`:

| attack | result |
|---|---|
| external entity, `file:///etc/passwd` in an attribute | **refused** — `reference to external entity in attribute` |
| entity expansion to 10^4 and 10^6 characters | expands; peak RSS 18–24 MiB across runs |

So file disclosure is not reachable through these calls on this interpreter, and
the expansion that is reachable is capped by the interpreter. The residual risk —
bounded memory and time if an operator parses junit XML from an untrusted source,
unbounded on an older interpreter without that limit — and the `defusedxml`
remedy are now stated in both READMEs. The probe script and its output are
committed at `batch_reports/scans/XML_RISK_PROBE_2026-10-18.py` so the numbers
are reproducible. Peak RSS is given as a **range** because it moved 18.4 → 23.9 →

## One more instance of the same loop, caught before commit

Writing this report reproduced the defect a **third** time: both the paragraph
above about the self-inflicted violation and the checkpoint's record of it quoted
the offending `sys.path.insert` line verbatim, container path and all. `git grep`
with the gate's own regex caught two instances in the working tree before the

That is three occurrences in one night, from three different directions — the
probe script, the gate transcript, and the prose describing both. The pattern is
worth stating as a rule for future sessions: **you cannot write about an
absolute-path defect without risking committing one.** Run the gate's own
check-8 regex — copy it out of `scripts/release_gate.py`, do not retype it into
a tracked file, because the regex literal **matches itself** and only
`release_gate.py` is exempt — over the staged tree as the last act before every
commit, not as a step in remediation. It costs a second; the alternative tonight
cost thirty minutes.

That self-match is a fourth instance of the same trap and the subtlest: a report
that documents the check by quoting its pattern fails the check. The gate's
author foresaw the general problem and exempted the gate file; the exemption does
not extend to anything that quotes the pattern back. Describe it, cite its
location, do not reproduce it.
